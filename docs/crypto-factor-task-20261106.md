# Codex 持续任务：研发可验证因子，提升成本后账户收益

任务日期：2026-11-06，Asia/Shanghai。执行仓库为本 Freqtrade 仓库，接续已提交的 `crypto-rd-roadmap-20261105.md`。用户已选择提交路线图后继续 P0/P1，并进一步要求“研发因子，提升收益”。本任务将该方向落实为有限、可证伪的研究工作；收益提升是研究目标，不是已实现结果或收益保证。

## 目标与交付

在同一初始资金、币池、成本、窗口和风险约束下，比较完整账户净值，寻找扣除手续费、执行成本代理及资金费后仍有增量的因子。每项候选最终交付代码、输入与源码 hash、运行前登记、全部尝试记录、成对评分表，以及保留／淘汰／阻塞结论。零交易、失败和负收益均保留。

本任务书是冻结路线图 v1 的补充；不改写 v1 的历史授权、参数、预算或试验登记。新增用户方向允许继续实现首轮因子研究，但经济回测仍以候选自身的准入证据为前提。P3、ML、超参数搜索、线上切换不因本任务书自动启动。

## 按顺序推进

1. **P0 可信度与风控证据**：验证固定来源、依赖和数据；完成已有预算内的因果诊断；保留缺失的事件、估值与历史时点证据。离线 RD1 风控状态机须对浮亏、部分成交、重复事件、重启和故障拒绝进行验证。
2. **P1 固定基线**：现金、BTC 持有、原版 AverageStrategy、固定 NFI X8，各按现货／合约、长／短窗、基准／压力成本复现，总计 32 个账户，另最多 2 次确定性复核。先完成短窗原生路径，再扩展其余已登记单元。
3. **首轮因子实现**：先实现 F1/F2 的因果输入、缺失拒绝和固定参数计算；通过未来数据扰动、窗口边界及时间一致性测试。数据或执行门槛未过时可交付计算代码，但不为经济回测伪造输入。
4. **有条件的 P2 配对研究**：通过候选准入后，沿用 v1 的至多 80 个完整账户预算（含控制、四个开发折和连续账户）。事前登记每个运行、所有对照与成本，不边看结果边追加参数。未通过准入的单元登记阻塞，不当作零收益账户参加统计。

## 首轮固定假设

| 候选 | 固定定义 | 用途与否证 |
|---|---|---|
| F1：168 小时动量 | 完整小时收盘价的 `log(close_t / close_t−168h)`；UTC 每日 00:00 决策，下一 5 分钟执行；正动量前 3，24 小时调仓，双市场均只做多，RD1 风控 | 旧趋势族的固定对照，不称新发现。少于 3/4 开发折净收益为正、压力连续账户净收益≤0、集中度或因果门槛失败即不通过 |
| F2：24 小时波动率缩放 | 24 个完整小时对数收益，样本标准差×`sqrt(24×365)`；仓位乘数 `min(1, 0.20 / sigma)`，缺失或零波动禁止新入场 | 只对 Average+RD1 控制做降风险配对。控制净收益≤0、最大回撤未降 20%、或保留不足 80% 的正净利润即不通过；不得用加杠杆补收益 |

F3 均值回归只复核历史失败归因；F4 资金费／基差待真实发布、接收、结算及同期报价证据，不把事后最终费率当作提前可知的因子。两者本轮新增经济运行均为 0。

## 成功判定

- 工程复现与经济合格分开。P1 完成不等于收益已提升。
- 经济判定沿用 v1：4 个开发折至少 3 个为正；连续压力成本账户净收益为正；经验证的 5 分钟估值最大回撤≤15%；单币正收益贡献≤35%、单日正收益贡献≤25%；按冻结的完整 UTC 日收益配对和多重比较规则评估。
- F1 对照现金，同时展示 BTC 和固定策略；F2 对照相同 RD1 的 Average。不得将未平仓浮盈、部分止盈累计或强制期末退出计作自然完成 campaign 的证明。
- 所有已观察历史窗口都保留选择偏差标签。真正的最终 90 天前瞻留出尚未开始；历史 bootstrap 不能消除旧搜索偏差。
