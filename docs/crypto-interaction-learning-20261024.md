# 25因子交互研究：固定模型与按月滚动模型

2026-10-24。已完成同一批25个价格、成交量、相对强弱及已知资金费因子下的三种预登记方案：线性固定模型、固定梯度提升树、按月滚动梯度提升树。**联合单位筛选未通过，没有新增可实盘版本，也没有把单位标签改称账户收益或胜率。**

本轮是此前已使用过的2024历史上的回顾及逐时前推研究，不是独立样本外证明。近期38份原生账户档案保持原样，本轮尚未新增经济账户。

## 假设、数据与时间边界

[冻结方案](../research/crypto/interaction_learning_plan_v001.json)研究价格路径与市场环境的交互是否比单独线性关系更能区分扣费后的机会。原NFI退出对照及单独相对资金费失败结论保留，没有改动旧实验。

- **25个因子**：5分钟/1小时/4小时/24小时收益，24小时VWAP偏离、20/96栏标准化偏离、实体与收盘位置、14栏涨跌压力、带方向成交量代理，BTC及同一时刻40币中位数相对强弱，已知资金费及变化、ATR、波动比、路径效率、成交量与名义流动性代理，以及交易方向。成交量代理不冒称真实主动买卖流。
- **机会总体**：39个山寨USDT永续合约，BTC仅作参考；每小时构造多空两个方向，小额固定1小时标签，大额每4小时构造固定24小时标签。只保留有限、完整的特征及预定ATR范围。
- **时钟**：源5分钟K线收盘后可用，另加一根K线处理间隔，假设在源时刻后10分钟开盘进入。历史已结算资金费主动延后1小时作为研究可用时间，不使用未来费率预测入场。
- **标签**：单腿单位初始名义金额的价格损益＋实际资金费（小时mark代理）−两次成交费用。基础费率5bps/边，主要额外成本3bps/边。没有在该阶段模拟止损、止盈、保证金占用、最小订单、强平或再投资。

准备出850,298条带方向及层级的特征记录；H1有421,740条已成熟训练单位，H2有426,224条特征单位。准备阶段没有计算H2评价标签。9组真实价格/资金费前缀检查通过；缺失及非有限特征被拒绝，包括零成交量引起的对数不可用值。

每个月起点M，训练窗口为[M−138日,M−18日)，校准窗口为[M−16日,M−2日)，两者均再应用相同24小时5分钟最坏成熟期约束。固定方案只使用7月前的一次拟合；滚动方案按预登记月份更新，先冻结当月预测，再允许其成熟结果进入后续月份训练。不是把整个后半年一次性拿去训练。

树模型固定80轮、深度4、最多15叶、叶最少200样本、L2=10、63个直方图桶，无早停或参数网格。使用独立过去校准段做非负斜率的概率校准。共14个模型包，每包包含净收益回归、净正标签概率及校准；这不是14个独立策略。

算法依据为[scikit-learn官方梯度提升文档](https://scikit-learn.org/stable/modules/ensemble.html)与[概率校准文档](https://scikit-learn.org/stable/modules/calibration.html)。模型在本地执行，固定版本依赖装在研究隔离目录，没有向外部模型发送源码或行情，没有更改原虚拟环境包。

## 冻结筛选与结果

小额要求校准概率≥80%、预测净标签≥8bps；大额要求概率≥55%、预测净标签≥16bps。每币每时刻每层只留预测净值较高的方向，同币同时两层合格时大额优先。预测选中的记录在查看评价结果前冻结，0/3/10bps使用相同记录。

对选中单位使用7日循环日块bootstrap，保留自然日内跨币共同波动及相邻日相关性；1000次重采样，并对3模型×2层×3成本的18项比较统一BH校正。预设还要求足够单位数、至少30个不同日期、正的区间下界及小额机会频率。**这些是研究假设，不是交易所官方上线门槛。**本轮BH不覆盖此前所有项目探索。

小额线性机会只有0.408个/自然日且表现负面；两个非线性方案没有选出满足80%概率门槛的小额机会，不能将空仓当高胜率策略。滚动大额的平均标签为正，单项原始日块p约0.04795，但统一校正后q约0.2985，未过0.05门槛，且没有合格的小额层。固定树大额正标签比例也未达到预设55%。18项均未通过完整筛选，不调整门槛或删除失败比较来制造晋级。

这些单位可相互重叠，**7,772个单位不是7,772笔可执行交易，90.96bps不是账户日收益、ROI或Sharpe**。必须再研究实际持仓容量与风险退出后的完整经济账户，才能计算可比较的账户收益及风险调整指标。原生账户评价继续遵循[官方来源指标协议](../research/crypto/performance_metric_contract_v003.json)。

## 事后诊断，只作线索

不重训、不改门槛、不移除记录的描述性检查发现：

- 线性小额75条中有51条至少一个特征超过训练标准差的10倍，最大约64.52倍；高预测概率在极端输入上失效。该诊断没有事后过滤这些亏损单位。
- 固定树小额最高校准概率约71.26%，按月树约77.65%，没有因接近门槛而降到其最大值。校准后高概率不等于实际完整持仓胜率保证。
- 按月大额只在7/8/9/12月选中单位，10/11月为0。7月平均−3.02bps，8月+78.00bps，9月+63.72bps，12月+167.78bps，正面结果有时间集中性。
- 按月大额与当时BTC过去24小时方向同向的比例仅24.47%。在模型已选择的同币同时刻改用BTC方向，描述性平均净标签为−57.47bps；这只比较同选时点的方向，不是独立策略基准或经预登记显著性检验的超额收益证明。

大额层因此保留为未验证的均值回归/环境交互线索，不能称为已验证alpha或“大额稳定收益”。如另设固定止损、仓位容量与完整退出过程的部件诊断，必须作为新假设预登记，保留本轮筛选失败，不能当作本轮晋级。小额高净胜率仍是未解决的目标。

## 独立核验及交付

- 7项测试通过：未来价格不改变过去特征、资金费可用滞后、校准不得反转失效模型、方向去重与层级优先、空仓/零标签不冒充盈利、统一比较校正、树的逐节点标量预测。
- H1/H2各120个单位由原始价格、已知因子及Decimal现金公式复算，净标签最大误差约2.39e−16；抽查跨币中位数及资金费可用时间一致。
- 独立核对14个模型的实际训练/校准人口与成熟时钟，并对84个预测做逐树/逐系数标量复算，最大误差约3.47e−18。另有70个内部标量预测检查。
- 模型、各月预测及选中记录的哈希保持不变；341份原生框架源码身份未变。全部六个执行阶段已结束，无真实订单、提交、推送或服务器部署。
