## 已完成的风险干预

保持原 NFI 入场因子、40 个币种、1 倍杠杆和每个组件 1000 USDT 的独立模拟钱包。没有为恢复收益调仓、转账、改变权重或挑选历史交易。

| 规则 | 有界版定义 |
|---|---|
| 累计入场 | 每个完整仓位最多 3 次，即首次入场＋最多 2 次追加 |
| 追加金额 | 每次不超过首单金额；禁止递增倍数补仓 |
| 生命周期 | 任意减仓后禁止再次加仓；每个 5 分钟周期最多一个追加提案 |
| 止损 | 固定在首单实际成交价下方 12%；之后不得放宽；解除原策略对止损退出的否决 |
| 单仓计划风险 | 初始 NFI 钱包的 2%；初始分配按 1.75% 预算并预留 0.25% 供已知资金费及舍入消耗 |
| 单仓保证金 | 累计成交成本不超过初始钱包的 20% |
| 账户新增风险 | 开仓/加仓必须有剩余 8% 初始资金的已知价格止损预算，及 80% 初始资金的保证金占用预算 |
| 持有期 | 最多 14 天；保留更早的原生退出和风险退出 |
| 状态缺失 | 拒绝追加并请求整仓退出 |

这些是交易准入与已知止损价格下的计划预算。跳空、未来资金费、失联和实际成交偏差可以使亏损超出预算；**不能解释成单仓最大实际亏损被保证锁定在 2%**。资金费增加时，总风险可能超过原准入预算；当前实现会阻止新增风险，尚未证明独立账户盯市熔断与自动减仓。

同一段 2024 原生账户的对比：原 NFI 单仓最多累计 19 次入场、最高保证金约 834.68 USDT、最长持仓约 55 天；有界版实际最多 2 次入场、最高约 65.49 USDT、最长约 3.08 天。2025—2026 连续账户中有界版最多 3 次入场、最高单仓保证金 91.49 USDT。未通过删除亏损交易或重算旧订单得到这些数字，全部重新运行完整原生账户。
