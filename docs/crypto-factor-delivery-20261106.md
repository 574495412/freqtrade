## 新完成的数据修复

固定 40 币的 L/S 共 80 份官方 5m mark 文件已完整生成，共 7,153,920 行。与原有小时 mark 对齐的 596,160 个开盘价全部相等，最大绝对差为 0。每行保留来源编号，能追溯至官方档案或缺口 API 响应。
