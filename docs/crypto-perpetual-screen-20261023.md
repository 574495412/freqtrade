# 合约研发筛查

后续目标更正：用户强调小额频繁交易与大额利润贡献的自主策略，而非复制带单员规则。新主线见[自主策略研发](crypto-autonomous-objective-20261023.md)；本页保留此前公开机制适配的失败记录。

2026-10-23。用户明确当前主要研究合约，参考 Omofun、Damorne。当前范围为 USDT 永续合约多空，分别评估频繁交易与大资金稳健；现货／合约 carry 退出主线，已有记录保留。

## 当前机制与来源

源码：[perpetual_flow.py](../research/crypto/strategies/perpetual_flow.py)。事前协议：[perpetual_flow_protocol.json](../research/crypto/perpetual_flow_protocol.json)；执行冻结：[perpetual_flow_plan.json](../research/crypto/perpetual_flow_plan.json)。

参考的是本机 CZ-Agent 的公开规则实现，读取版本 `9dab77ec002fda1b2539ab0238cc60ad65694cac`，没有导入带单员标签、私有账户状态或正在运行的服务。快照与 SHA 保存在协议中。

- Damorne：20分钟收益横截面分位、相对市场残差、成交量放大排名、流动性排名和真实主动买卖方向；方向首次成立时触发，每根只选一个标的。原3分钟流量改为真实5分钟档案，不虚构持仓人数比。
- Omofun：参考盈利止盈和再入场的机制。原 FastAttention 还使用 TradFi 标的及公开持仓比；这些条件没有完整移植，因此当前候选不等于复制 Omofun 的完整策略或收益。
- 40币真实5分钟成交量面板共1157.76万行，资金费来自原始事件。已验证前缀因果性、缺失数据恢复边界和同根信号选择规则。

`PerpFlowFast` 在当前成交方向确认消失、1%价格盈利、60分钟持仓或固定2ATR止损时退出。`PerpFlowFunded` 使用相同入场，1%价格盈利时部分止盈，只允许在真实净盈利结算且后续完整K线继续确认方向后追加一次；追加金额至多初始的一半，追加至固定止损的风险至多等于已实现利润，2%价格盈利全退。

两版均为1倍永续合约，允许做多做空；研究本金1000USDT，单笔上限150USDT，最多4仓，种子仓风险预算0.25%。1倍不代表现货。先比较基础每侧5bps手续费及额外0／3／10bps压力；额外成本是费用代理，不是盘口成交仿真。

完整账户使用原生 Freqtrade，统一计算部分止盈、追加、资金费和持仓浮亏。没有无限摊平，也不把部分退出或追加计成完整交易。当前引擎不支持同币同时双向持仓，因此不是完整的对冲网格实现。

## 本批多空候选

运行目录为 `user_data/crypto_quant/perpetual_flow_run_v001`，2024年训练六个完整账户均已结束。冻结条件为：三档成本均盈利、PF至少1.1、至少30笔完整交易、风险回撤不超过10%；Fast另要求日历日日均至少1笔完整交易。阈值是事前研究假设，不是用户收益承诺。

0bps额外成本仍含基础5bps／侧。两版均实际成交多单和空单。3bps档直接版多2659／空1783笔，追加版多2630／空1769笔；持仓中位数均5分钟。直接版4041笔因公开方向确认消失退出，追加版4205笔，说明短时方向翻转产生了很高换手。

在同一3bps档，直接版费用809.73USDT，含资金费但未扣交易费损益−38.82USDT；追加版费用799.19USDT，未扣交易费损益−49.30USDT。问题不只是成本：入场机制在这轮账户中也没有展现扣费前正收益。两版最后交易分别在2024-02-03 13:10／10:00 UTC，账户剩余约151USDT，此后全年没有新成交。全年日均12.14／12.02笔是固定分母的统计，不能解释为全年持续运行的有效频率，也不能把相似终值视为有效回撤控制。

追加版3bps档发生257次部分退出、36次真实追加，完整交易仍为4399笔。独立审计验证了每个完整账户的成交现金流和最终库存、最多两次入场／两次退出、追加发生在实际部分止盈之后；这不等于独立重放所有因子和风险回调，也不证明追加机制具有超额收益。预算至固定止损的价格风险不含跳空及额外执行费用。

包括 Cluc／Quickie 在内的12个原生账户共32263笔完整交易已完成 Decimal 现金流核对，单笔最大差异约0.00000001USDT。可复算入口：[audit_contract_screen.py](../research/crypto/audit_contract_screen.py)；结果：[contract_screen_audit_v002.json](../user_data/crypto_quant/contract_screen_audit_v002.json)。70项工程测试通过，包含10项新合约因果性和追加边界测试；工程通过不改变经济淘汰结论。

本批没有合格候选，固定对照为现金；TradingAgents没有被调用，2025／2026和大资金规模账户未启动。没有按已见收益反向选择方向、提高杠杆或改阈值重新包装失败结果。

只有基础经济筛查通过才会进入后续年份和10000／100000USDT完整账户规模实验。当前历史全部属于回顾式研究，币池含当前可交易交集的生存者偏差，不能称为独立未见样本外。

## 运行边界

当前策略仅有历史因子面板，主动拒绝 live／dry-run 启动；通过经济筛查后仍需实现并验证当前K线数据源。尚无新合约版本取得实盘资格，没有启动真实下单或变更 CZ-Agent 服务。旧模拟组合保持停止。
