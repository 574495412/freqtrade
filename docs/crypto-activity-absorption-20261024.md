# 真实成交流与成交活跃度：同样本吸收事件研究

2026-10-24。三组特征、18套月度模型、9项策略／成本比较及4项配对预测增益检验已完成。**没有合格入场预测，新增成交流／成交活跃度也没有可确认的条件增益。本轮不进入完整资金账户，不产生上线候选。**大额排序组件的先前结果没有在本轮重新验证。

## 与此前实验的区别

此前25个模型输入里的`flow12`是按K线涨跌方向加权的成交量代理，不是真实主动买卖流。早先6币条件因子实验确实使用过真实taker流，但使用不同标签与线性模型，旧失败保留。

本轮复用[币安官方档案定义](https://github.com/binance/binance-public-data)中的真实quote volume、taker buy quote和成交笔数，检验价格吸收与成交活跃度。成交均额是quote volume／成交笔数，不能据此识别大户、账户数量或订单拆分。

共同机会为完成的5分钟K线：拟入场方向的真实主动流≤−0.25、K线实体方向不反对入场、方向化收盘位置≥0.5、quote volume≥此前12根均值的1.5倍，且上一根没有同方向触发、上一根主动流已知。买入例子是主动卖出较强、价格却收在高位；这是待证伪假设，不是确认的吸筹信号。

固定40币来源于此前列表，其中BTC仅作参考，39个USDT永续参与研究。没有按本轮结果换币或调触发阈值。特征在bar open＋5分钟可知，假设再缓冲一根、于＋10分钟入场；资金费特征维持事件后一小时可见。

| 组别 | 输入数 | 相同触发机会内的模型输入 |
| --- | ---: | --- |
| Price | 25 | 原量价、BTC相对收益、资金费与状态特征，改为保留5分钟时点 |
| Flow | 29 | 加真实5分钟／1小时主动流、相对上一小时的流变化、流与实体收益的条件响应 |
| FlowActivity | 33 | 再加quote volume、成交笔数、平均成交规模相对前12根的对数变化，以及成交活跃度×反向主动流 |

**三组都使用同一吸收触发条件，该条件本身已经读真实成交流。**比较回答的是条件内新增模型输入的增益，不是“完全不使用成交数据”与“使用成交数据”的全量差异。共同完整样本使用全部33列可用性，不把缺失过滤误作增益。

## 冻结、训练与执行假设

先冻结不读收益的[事件登记](../research/crypto/activity_absorption_enrollment_v001.json)，SHA256 `0d7c68146aa9239966c7ddf841cb6395de7af8af67c3e226e6c36dae7f2df5cb`。核对520个月档、4,573,440条原始K线后，得到18,175个事件，其中15,659个发生在非整点；此时没有计算收益标签。

随后冻结[模型研究计划](../research/crypto/activity_absorption_plan_v001.json)，SHA256 `62af6c645aed026bfe219eb9656d17ba5507f4bf9e05eac67421b68d23bbc3f8`，固定23份源码摘要。2024上半年准备7,585条单位路径，下半年10,538个特征事件。2024已经用于项目研发，不是全项目独立样本外。

每月训练窗为月初前138日至前18日，校准窗前16日至前2日；标签边界统一按24小时＋5分钟保守剔除，不因未来提前退出而放回。三组同一月份使用完全相同的训练、校准和预测row ID。每组每月拟合固定参数的直方图树分类器与净损益回归器，再单独校准概率；6个月×3组共18套模型／36个基础估计器，没有参数搜索。

小额执行维持上一轮原生盘中净0.25R止盈、固定硬止损与4小时上限，受保护成交回调修复继续使用。同根止损先于ROI；资金费会改变净目标价格；一次入场、一次全平，无追加及部分平仓。单位路径包含实际资金费及价格精度代理，仍不是资金账户或真实盘口成交。

入场预测门槛仍为净正收益概率≥80%且预测单位净收益≥8bps。这是既有项目假设，**不是官方交易所门槛**。基础费5bps／边，额外成本0／3／10bps／边；每档重新计算完整退出路径。3bps用于拟合和四项预测增益检验。

## 核验与后续

- 520个原始档案摘要符合此前官方校验记录，OHLCV五字段与原生数据对齐。40币的整点25特征与旧实现逐行一致。
- 9个实际截断前缀检查通过，涉及941个事件行；8项新增测试覆盖原始字段、非整数／非法计数、零活动未知、未来变更不影响过去、事件去重和Decimal算术。
- 独立审计直接读取CSV字符串，重算39币117个事件的936个新特征值与触发／发布时间，通过。首次审计源码快照及旧收据保留；随后只修复两处静态检查提示并重新核对同一117个样本，没有将重复核验计成更多独立样本。
- H1抽样120条、H2三成本各120条，共480个不同阶段／成本路径核验；原生受保护回调、退出时刻、退出价、硬止损与Decimal现金一致，最大单位现金误差2.56×10⁻¹⁶。
- 18套训练／校准人口核验通过；108个标量树遍历预测与库结果一致。四项全样本配对损失均值另以Decimal复算通过，13项BH调整独立核对。
- 原生框架341份源码和计划冻结23份研究源码保持不变。六阶段进程已终止退出0，没有后台等待或新实盘订单。

该机制按现有项目约定淘汰，不降低门槛补信号，不继续在同一触发器上堆相近成交字段。下一轮应采用有独立经济解释的持仓／执行机制，重新冻结完整账户假设；若涉及挂单或更低成本，必须建立相应成交证据，不能直接把费率改低当成盈利。保留[此前大额机会排序线索](crypto-intrabar-joint-accounts-20261024.md)，它仍缺多成本、跨时段及独立前向证据。

完整资金账户后续继续使用币安官方来源的ROI／PNL／夏普／回撤／完整持仓指标，补充索提诺、PF、期望值、交易频率与两层净贡献；本轮不虚构无交易账户的这些成绩。主比较集仍为50份既有档案，没有增加账户或独立策略数量。
