# 原生分时段持续持仓：8bps转正，完整晋级仍失败

**没有合格的新高收益策略或组合。** 本轮完成16个新Freqtrade进程，其中12个检验持续持仓政策、4个复跑原策略做技术对照；另复核复用8个旧原生账户，不把它们算作新增回测。同一完整窗口、两个实际500USDT钱包相加，边界持续持仓组合在8bps净收益+6.03%、最大小时回撤48.61%；但2026年连续切片亏损44.98%，15bps完整窗口亏损51.63%、回撤63.44%，固定晋级线失败。

结果是原生含成本/资金费合同下的条件模型收益，不是独立样本外或实盘资格。原生资金费采用含开、闭边界累计，BTC同整点换向有重复事件归属；该限制没有被“资金费输入完整”消除，详见下面的逐事件诊断。

本轮两种持续持仓政策均在看到其财务结果前冻结：

- **BoundaryCarrySource，主候选：** 在边界T用已完成的T−24h/T−12h端点决定方向；同方向保留原数量，方向变化时由原生先平旧仓再在T开新仓。
- **ClockMatchedCarrySource，归因对照：** 与旧版一样在T平反向旧仓、T+5min进入新仓，同方向则保留。区分持续持仓政策与提前5分钟进入的影响，不能事后挑其中较好的时钟晋级。
- **BoundaryCarryLong：** 同样边界和输入支持条件，恒定做多，持仓持续。另保留旧PassiveLong作为初始时点不同的参考，二者不能混称相同时点账户。

持仓内数量固定，只有平仓后才由原生可用现金重新定仓。这更接近方向不变时不交易的含义，但仍**不等于论文每时段免费重置单位名义敞口的财富公式**。原论文Kraken USD现货与本地Binance USDT永续也不同；没有声称完成论文原样经济复现。

## 实际持仓与敞口

每个来源腿有1216个时段决策，BTC在570个边界、ETH在626个边界实际持续同方向持仓。各成本BTC646笔、ETH590笔原生生命周期，均只有一次入场和一次退出；新持续持仓账户没有无法解释的未成交意图。同方向没有追加单或人为平仓。自然退出都对应相反来源目标，其他持仓在终点强制关闭。

1×是原生杠杆设置，**不是每小时总名义额/净值必然≤1**。持有原数量、价格和资金费变动会令该比率漂移。按实际持仓量和小时mark独立复算，主候选最大BTC/ETH比率15bps为1.2896/1.1971，8bps为1.0806/1.1931。本轮没有通过免费调仓或追加保证金把它伪装成恒定100%风险；这也使其与论文单位仓位公式不同。

相对旧版的收益改善，是包括交易数量、现金、重新定仓、持仓时长和资金费变化的整体政策效果。即使同钟对照保持了反向时的旧时点，也不能把差额全部叫作在固定成交上减去手续费的收益。
