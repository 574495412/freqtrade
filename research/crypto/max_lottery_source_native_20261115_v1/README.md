## Native 所有权、输入与时钟

上游 Freqtrade 固定 `c051e9065c5b677f03817dd1f83cb980af1ed684`，核验清单内595个原始文件。新增 `freqtrade/data/max_lottery.py` 与 `MaxInputs.py` 是本地研究扩展；实际 StrategyResolver → IStrategy → DataProvider 计算和映射分数。财务 `ft_bot_start` 始终拒绝，不能把诊断程序变成无交易现金账户。

原始40币顺序及完整目标账户窗口仍为 **2025-01-01 00:00～2026-08-31 23:00 UTC**。每168小时决策一次，锚定2025年1月1日，不按年份重置。D日00时只用刚完成的 D−1 日线及此前28个日收益；映射到 D日00时的1小时行，原生一根延迟对应 D日01时。预测标签取 D日01时 OPEN 至168小时后 OPEN。

只有终点仍在完整窗口内的86个标签进入预测分析，最后完整决策是2026年8月19日；8月26日尾部保留未成熟，不填零。**这不把资金账户窗口改成8月19日**。若准入，资金阶段还须按预先写明的卖旧／后续时刻入新规则执行，该实际持有期与预测标签不能混同。

本轮核对 **80 份原生日线／小时文件**：日线1796个共同观察，40币，未丢币、补价或改原数据。17,200个独立标量特征检查、5,409,600个实际原生小时映射单元，以及三个实际未来边界的截断／扰动检查通过。937,400个前缀字段单元的两种检查有重叠，不当成独立样本。21项规则检查、生产模块完整 Ruff、本地研究脚本语义检查通过；这不是正式全策略 lookahead／recursive 认证或经济有效性证明。

同日期十个已声明对照做了有限去重：六个共同40币视图、旧八币残差动量及三个旧六币流动性视图。平均绝对 Pearson 对低波动28日约 **.86328**、同月偏度约 .71794；未超过 .99，不等于全 Registry 去重或独立 alpha。来源整体假设在本地失败，不是证明原论文在其市场和期间无效。
