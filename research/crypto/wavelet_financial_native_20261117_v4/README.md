## 来源、边界与保留的失败

源策略为 `nateemma/strategies` 提交 `9bb7dab5df53203e69f60336749551a40767af0b` 的CPU路径，保留原始15m、startup128、初次训练1000与每2500根重训练规则。首次预测2025-01-10 02:15才可用于执行，此前现金等待期包含在完整账户。实际数值模型为小波系数的LightGBM多输出回归。这里验证的是固定CPU路径及本地导入桥接，并非完整TensorFlow/MLX框架启动或作者已公布收益复现。

NFI采用5m限价策略，小波采用15m市价策略及5m明细撮合。比较统一了资金、窗口、币种、原生引擎、共同OHLCV及合成成本，仍受各源策略执行规则和历史撮合假设限制。小时OPEN估值包含平仓费用储备；没有真实交易所排队成交认证或独立样本外盈利证明，也不与40币永续账户作全局排名。

所有原始失败保留：首次预检查遗漏datadir；首次财务尝试在Backtesting.start之前被旧研究标志拦截；旧退出审计器漏识别源标签 `model_exit `，修订版仅补充该标签并重新通过，不改成交；图形模板和环境失败亦保留。源预测归一化单位与原始百分比阈值的语义限制在收益出现前记录，未因亏损修正。

原运行日志全文位于 `progress_journal_before_final.md`，其进行中表述已过时。`execution_complete_attempt2.json` 是账户执行刚结束时的历史快照；当前总体终态见 `completion_status.json`。代码/审计通过与经济门槛通过严格分开。本候选研究完成并淘汰，持续研究目标仍活跃，未下单或部署。
