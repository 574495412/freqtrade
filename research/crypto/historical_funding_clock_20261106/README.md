# 短窗内的资金费和盘口时钟抽查

按登记抽取 2026-11-01 UTC 的 BTCUSDT 和 SOLUSDT USD-M 数据。6 个资金费身份各被观察两次，精确结算毫秒、费率、标记价格和费率类型均与冻结 Binance 公共回执吻合。冻结原生费率也逐项吻合。两个 08:00 结算的原始时刻为 `08:00:00.003`，其原生小时键为 `08:00:00.000`。原始毫秒保留在证据中。

六个身份在注册样本中首次被采集端观察到的时刻比结算晚约 300.014 至 300.031 秒。这是采样观察界限。交易所最早发布时间、策略实际历史接收及私人账户结算和成交仍需各自的来源回执。次日 00:05 的一个普通日期请求返回 401。[Tardis 原始 HTTP 格式](https://docs.tardis.dev/api/http-api-reference) · [资金费采样说明](https://docs.tardis.dev/historical-data-details/binance-futures)

00:05 的一分钟含 11,316 条独立买卖报价和 4,245 条盘口增量。最早采样资金费之前，该分钟里已有 SOL 报价，BTC 的第一条独立报价较晚。分钟切片缺少初始快照，因此该切片本身无法桥接增量。随后单独登记并取得 00:00 至 00:06 的连续切片，其中各有一份真实初始快照。重叠分钟的 4,245 条消息逐条吻合。

| 合约 | 有效盘口观测 | 双侧 20bps 完整 | 首次采样资金费之前完整 |
|---|---:|---:|---:|
| BTCUSDT | 13,451 | 0 | 0 |
| SOLUSDT | 12,057 | 12,057 | 10,056 |

盘口按实际采集顺序和 `pu` 链重放。BTC 在首次资金费观察前的盘口买侧超出原快照边界，卖侧覆盖完整。记录保留买侧可见量下界。SOL 的完整深度属于上述样本的 bid/ask 锚定诊断。两币均保持原 RD1 合同和全窗口准入要求。

`capture.py`、`audit.py`、`anchor.py` 各自先登记，再捕获或审计。原始数据与规范化报价保存在隔离的 `user_data/crypto_quant/rd_program_20261105_v1/funding_clock_probe_v001`，`verification.json` 记录 9 份回执及衍生结果哈希。历史规则、原始发布时间与策略接收时刻、账户事件顺序和全币池全窗口覆盖仍待验证。本轮金融运行数为 0。
