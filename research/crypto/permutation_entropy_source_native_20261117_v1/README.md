## 完整账证与机制诊断

4个有效钱包合计368笔原生Trade、1155个模拟成交、58368个小时估值点。统一末端全部自然平仓，未实现损益与退出费准备均为0，无原生终端强平单计入收益。20bp/1000钱包毛已实现价格损益248.1308 USDT、已付费用130.4405、净利润117.6903；13bp分别251.7940、86.6463、165.1477。各档资金路径不同，不能把费用差简单当成相同订单的成本扣减。

独立脚本从原生ZIP订单重建数量、现金、费用和逐小时NAV，不导入候选因子；最大NAV误差5.5441e-8 USDT。另复核9724次预算、19448个目标数量，预算与审计净值误差最大1.14e-13；所有非终端成交均在完整六小时信号之后的注册时钟。

原始完整信号价历史每币30144小时，2023-03-25起，复用封存字节、未填补缺失。纯作者函数重新计算完整历史，与修正版实际40,192条原生门控追踪逐条一致。共同窗口每币2432个计划六小时目标，BTC原1296个正目标保留871个、ETH原1086个保留601个；这是信号目标统计，含初始00:00尚无原生调仓事件的计划目标，不当成成交。每钱包实际预算事件为2431次。

5项测试通过：源码含并列值/常数序列一致、真实截断、时钟与阈值排除当前、未来扰动、缺失与非法输入拒绝，以及完整历史的**熵值和实际门控完全相等**。新增信号模块/测试/分析代码Ruff通过，辅助脚本另做基础语法与未定义名称检查。

## 首版失败与修正记录

首版仅以容差验证数值；独立复核发现`np.log2`、累计和与归一化顺序带来的最大4.44e-16误差，在滚动中位数等值边界改变了门控。完整历史BTC有1个小时差异、未落在六小时调仓点；ETH有1个差异，落在2025-07-23 12:00共同执行窗口。单个信号差异仍可能改变后续现金路径，故不能因数值小就认证来源一致。

首版4个原生钱包共有364笔Trade、1148个成交和58368估值点；原输出、代码字节、错误日志及冻结文件全部保留，但不用于上表策略评价。修正按作者`value_counts`的降频数顺序、`math.log2`和归一化乘法顺序计算，阈值、方向、权重、成本和日期完全未改。`correction_protocol_v2.json`在4次修正重跑前说明总尝试上限由4扩至8。新旧模块字节均可核查；原始冻结中指向根模块的旧SHA由 `implementation_v001/ordinal_entropy.py` 归档保全，不能声称首版根路径始终未变。

另保留两个辅助错误：首次分析组合曲线直接比较不同Pandas时间分辨率而失败，v2只将等值检查统一到ns；最初分析输入登记错误解析TradingAgents相邻路径，未启动额外金融进程。没有修改源信号、删掉不利账户、缩日期、改组合权重或重定成本来修复这些错误。
