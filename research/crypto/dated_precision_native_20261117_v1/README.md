# 加密原生历史价格规则接入

本批继续原有加密目标，为同合同完整账户重跑接入历史价格精度。完成了本地原生模块扩展和21项合成工程测试，尚未启动完整资金账户，也没有新的因子、组合收益或已修正的X8收益。原有失败、旧账户及上一批封存文件保持原状。

## 来源和新证据

固定官方引擎仍为Freqtrade c051e9065c5b677f03817dd1f83cb980af1ed684，595份vendor文件SHA核对不变。此前GitHub精度函数实际以整月OHLC最大位数推算月初规则。本批修改位于本地原生Backtesting及新增dated_price_precision模块，属于本地扩展，不称为上游官方功能。

本批通过web工具读取[币安4月公告原文](https://www.binance.com/en/support/announcement/detail/bb0c704f3ca344c7a8741c551dd624ce)：CRV和GALA分别于2026-04-29 06:30、06:40UTC改变价格步长，各暂停新下单、撤单和改单一分钟，原挂单保留原精度。与44条旧订单观测回连，有18条在相应生效时刻之前已使用公告中的新精度。这是旧模型提前使用新网格的来源对比，不是利润被抬高的证明，也不提供公告发布前的完整连续规则历史。相同成本情景之间存在重复账户，18条不是18个独立样本；已记录成交价仍在两种网格上。

RUNE的11月公告目前仅取得原站索引文字，原页打开重定向到公告列表；作为线索保留，没有提升为完整原文准入。SOL未找到匹配的有日期来源。读取6月17日另一原公告后，确认其表格不含CRV，因此没有把该公告用作CRV证据。直接HTTP请求三份公告均返回202和零字节，失败回执保留；成功web提取与失败原始下载明确分开。

公告展示的发布时间没有显式时区，未自动改称UTC；历史first-seen也未认证。notice_events.json的known_at仍为null，真实40币全窗口规则书尚未准入。本批没有观看新的X/Twitter、YouTube或抖音视频，也没有从它们准入新策略规则。

## 原生接口扩展

- 不改变默认价格行为的两个接口，分别在入场定价、请求替换价和退出订单创建时接入。默认订单结果与此前封存的本地引擎对比一致；此前交易模型工厂保留。
- 冻结的PriceRule/PriceRuleBook区分有效区间、已知时间、来源SHA与暂停状态。缺失、晚知、重叠、无效tick和合同漂移直接拒绝，不回退到未来行情或当前快照。
- 显式选择的DatedPricePrecisionMixin用于离线Binance逐仓永续原生回测，目前限价订单。新退出订单读取当时规则，不修改旧Trade的成本精度或旧Order价格；原生挂单检查和成交仍由原引擎完成。
- 原生入场的“报价等于开盘价”和requested_rate路径也到达规范化接口。新价格在原生仓位定量前处理；旧挂单在规则变粗后仍能按旧价格完成原生成交测试。
- 暂停期间的下单、退出、挂单成交及撤单路径中止此尚不受支持的账户，完整窗口validate_window同样拒绝。尚未实现一分钟暂停区间内的完整细节行情撮合，没有删除或跳过暂停分钟以制造收益。

这些代码不验证来源本身是否为交易所完整历史合同。数量/名义金额过滤器、历史杠杆档位、停牌细节、成本基准舍入及真实手续费/资金费仍需分别准入。该Mixin没有接入旧收益运行器、缓存或服务。

## 验证与限制

21项工程用例通过，调用实际本地原生_enter_trade、_exit_trade、_try_close_open_order和Order关闭方法，覆盖规则切换、新退出订单、旧挂单跨更粗网格成交、未知/晚知/重叠规则、前缀不变、完整窗口缺口及暂停拒绝、合同漂移、默认原生订单回归。钱包接口在这些单元用例中是明确桩；旧挂单成交用例仅将资金费累积设为空，不替换订单撮合。**未调用完整原生start，不属于账户收益回测。**

初次测试3项失败来自合成夹具把98.125在0.01tick上的原生half-up结果误写为98.12；改为98.13，未改生产舍入规则，原日志及修改前测试保留。首次验证器误读旧清单的字典结构，失败日志及源码保留；修正清单读取后通过。Ruff和git diff --check通过。

下一步仍是获得并准入原40币、原完整窗口的规则历史，并在原生模块实现暂停区间的时间细节合同，随后以隔离缓存、原资本/杠杆/币池/费用和固定策略重跑完整钱包。每个新账户重新核对AXS/TRB未知资金费时点的暴露。独立成交、资金费、现金、共同终点净值审核完成后，才能比较新机制与真实资金分配组合是否提高收益。
