## 原始来源与明确错误

固定 [mikemarshall01/crypto-quant-strategies@6f039e6](https://github.com/mikemarshall01/crypto-quant-strategies/tree/6f039e64d6d13227cdc5a79bbd9d78b093468cd0)，MIT完整许可保留。实际git ls-remote取得提交；5个固定提交原文件均HTTP200并绑定SHA，没有声称Git blob或全仓审计。阅读范围逐项列在source_intake.json，未运行作者下载器、notebook顶层、统计网格或资金引擎。

源第10项的固定状态规则是：十年名义收益率在10个**日历日**内上涨，且DXY的10日对数变化为正时，把BTC目标比例从1降至0.25；其余为1，并按日滞后一格。机制是假设美元/折现率收紧构成加密逆风，相关性或Granger可预测性不证明因果。源100个相关/FDR网格使用全样本，未与训练/实际交易分离，也没有实际驱动固定两个输入的选择，不能称本地通过FDR或预测验证。

**源账户计算把BTC对数收益当简单收益复利。** 原码先`ret["BTC"] = np.log(panel["BTC"]).diff()`，再将`bh_ret`交给`(1+r).cumprod()`。确定性合成价格100→200→100，真实买入持有末值应为初值1倍，源等式却得0.5195469861倍（−48.0453%）。这证明收益换算不一致，不是作者真实策略亏损，也不是一个本地投资账户。完整证据、AST绑定和公式见source_witnesses.json。

目标比例乘日收益还隐含现金与每日实际数量再平衡；仅按目标比例变化收费会遗漏比例不变但价格漂移时的再平衡成本。原账户没有完整初始/末端资金、数量精度、最低名义额等契约。修正单位、建原生现金账和选择信号是不同工作，不能将修正后的模型冒称作者原账户复现；本轮未代跑任何独立账户模拟器。

## 本地原生输入扩展

`freqtrade/data/macro_transmission.py`持有不可变原始快照，验证精确标识、INDEX类型、1d频率、时间戳单位、原声明时区、唯一有序日期及数值。名义收益率可为负，美元指数须为正。原始条形时间戳是标签，不冒充发布/收盘时刻；晚于实际获取的条形标签拒绝。

`MacroTransmissionDataProvider`继承固定上游DataProvider，只读BACKTEST使用。原生`_set_dataframe_max_date`供给回调时钟，普通行情缓存/切片仍由父类处理；清缓存同时清除宏观观察钟。返回结果是副本，未来数值/记录扰动或截断不能改变此前输出。没有入场、订单、资金、假想收益或新Registry分数。

默认模式要求快照实际已取得，再允许当前计算读取其历史端点；这不认证那些数字在历史当时已发布。对历史端点的日期筛选与当前知识截止分别声明，不能把“今天知道过去数字”倒填为“当时知道该版本”。

另立敏感性模式，**假设源会话日次日06:00 UTC后可用**，十日端点各取最后非空原始报价、最大年龄120小时。旧报价的日期、年龄和其后的空行数都返回，不捏造新的观测收盘；过期或无端点保持unknown，目标比例为None，不默认空仓或全仓。该模式使用当前快照构造回溯输入，是本地模型，不是Yahoo/ICE/Cboe真实发布/节假日证据。ICE美元指数期货的交易与结算说明也不能认证Yahoo现金INDEX日线时钟。
