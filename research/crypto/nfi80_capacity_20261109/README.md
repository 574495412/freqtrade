# NFI X8：2026 年至今，80 币、3×与12仓比较

用户明确要求测试 80 币、3×杠杆、最多12个并发仓位，并把窗口指定为2026年至今。此次为隔离历史研究，不启动主网或模拟交易服务。

## 冻结合同

- 原版 NFI X8 v18.0.146，来源 `1af55971d3a64703ec449078e09fdec257d0d3c6`。执行引擎为既有固定 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`。
- 四组：1×6仓、3×6仓、1×12仓、3×12仓。每组独立1,000 USDT空仓起跑、逐仓、unlimited stake、0.99可交易资金比例；信号、首仓逻辑、加减仓和退出不变。实际首仓金额仍会受槽位数、杠杆和钱包状态影响。
- 同一份80币名单：作者固定版本的回测名单与黑名单，要求开测前至少60天已观测历史，按2025-12-31的典型价×基础币成交量估计值排序。该成交额公式来自原生 VolumePairList 的K线模式。名单只冻结一次，实际原生回测使用 StaticPairList；这不是动态 VolumePairList 回测。
- 使用缓存中的当前市场规则并保留其日期，因此币池仍有现时资格/存活偏差，不构成历史逐时可交易资格证明。
- 开始于2026-01-01 UTC。取数结束于2026-11-09 05:05 UTC（北京时间13:05），全部价格K线已收盘。共同账户估值终点为最新完整5分钟K线的开盘时点05:00 UTC；该时点的交易尚未处理。原生末尾强制平仓另列，不能混入共同边界收益。
- 单边15与8 bps两档成本代理，分别包含手续费及滑点等价预算，另计原生资金费模型。先比较15 bps四组，再运行8 bps四组。未把旧40币收益混作80币对照。
- 本次是新合同，研究回撤上限50%，不回改此前失败实验，也不是新增的实盘止损或亏损保证。所有结果保留，不根据结果更换币、窗口或参数。

## 技术修订：原生预热历史

首个技术尝试使用v001输入，日线前缀被本地范围截到365天。发现原生加载器请求800根日线后，主动中止首个账户，未接受或检视其收益；中止状态、进度、原输入与日志完整保留在v001目录。经济参数、80币名单、成本、窗口均不变。

v002复制并保留原有输入，逐币通过官方日线API补足开测前800天可得历史；不足800天仅允许源于真实上市历史较短，不补造上市前价格。当前运行使用v002原生计划。两次合同和技术修订记录均保留，不能把中止账户计入有效收益比较。

## 数据与执行

`protocol.json` 和 `universe.json` 在新账户收益产生前登记。官方 SHA-256 校验的 Binance Data Vision ZIP 补齐行情与资金费；当天/缺档部分由无密钥公开 GET 补齐。原始毫秒资金费时点保存在私有工作数据目录，当前原生小时资金费模型只接受小于一秒的归小时偏差；保留其模型边界，不声称精确到账或盘中清算复现。不补造价格，不把缺失资金费记成零。

持仓匹配、钱包、资金费、杠杆、加减仓、退出均由固定 Freqtrade 原生 Backtesting 运行。现有研究包装仅提供输入冻结、匿名市场元数据、缓存存储及只读净值观察，不新造撮合或账户引擎。它是原生 Freqtrade 回放，不是 Vibe-Trading SignalEngine 回测或 bench 注册代替执行的结果。

磁盘只剩约14 GiB，因此把既有自产 Pickle 缓存改为低压缩级别的无损 Gzip，原始数值、列和行序均保留。一次只跑一个账户，6 GiB RSS、三小时单账户时间守卫。存储回归检验逐位浮点值、热缓存修改后的驱逐持久化、空表及键顺序。仅成功账户自己的临时缓存会在归档后删除；源数据、原生成交归档和净值不删。

五分钟估值从既有只读 Observer 扩展：使用同刻的官方5分钟标记价开盘，完整持仓估值包含原生累计资金费和退出费预留。所有小时之外也观察持仓，不再把小时回撤当作五分钟回撤。五分钟仍不能覆盖K线内部的最深回撤和真实清算费用。
