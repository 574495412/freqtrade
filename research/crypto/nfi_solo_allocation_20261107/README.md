# A08 NFI X8 无其他多头时的首仓放大

沿用固定的 Freqtrade 引擎与 NFI X8 源码。只对原生纯 Top Coins 多单的首仓调整金额。原生账户当时没有其他多单或待成交多单时，首仓为原额的 1.5 倍。已有多头时使用原额。仍以交易所限额及钱包约束为准。原生交易信号、方向、1× 杠杆、六槽及加减仓和退出回调保持相同。首仓改变会间接影响后续规模。 [注册规则](protocol.json) · [Freqtrade 仓位回调](https://www.freqtrade.io/en/stable/strategy-callbacks/#stake-size-management)
