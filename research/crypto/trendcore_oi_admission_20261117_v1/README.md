# TrendCore 默认OI覆盖层：原始数据准入未通过

本轮完成974天、280,382行Binance原始持仓量数据核验。**默认OI版本仍不能计入完整账户收益比较；没有启动新金融回测，也没有新收益结论。** 上轮无OI版本的4个原生钱包与全部失败门槛保持不变。

## 来源与冻结规则

固定作者仓库 [d62416ea](https://github.com/0x-boss/quant_crypto_strategy/tree/d62416ea52620c2e9f53584dd5347ddf6718efd2)，核对 `scripts/fetch_metrics.py`、`scripts/fetch_binance.py` 和原始 `BTCUSDT_oi_daily.parquet`。作者覆盖层为日度美元OI取对数、365行滚动均值/标准差、滞后1日、z限于0至2、仓位乘以1−0.5×z/2，最后限制总仓位。没有改动强度、窗口、门槛或组合权重。

冻结的数据准入要求是核对每日原始观测、明确时钟与缺失，不静默补值。作者宣称的收益与上一轮无OI收益均已见过，因此本轮不是盲选或独立样本外验证。[Binance公开数据说明](https://github.com/binance/binance-public-data)与作者下载器均指向官方公开存档。Binance连接器对所需历史区间返回400；没有将失败响应当作数据，也没有反复请求该接口。

## 因果时钟和账户边界

六小时价格组为左标记，只有组结束后可执行。若后续恢复默认OI版本，应在**执行时间减6小时的原始组标签**计算作者的日滞后OI，再于原生下根K线执行；尤其00:00执行时不能误换成新日OI。覆盖层还必须在总仓位上限之前应用，不能对已经限仓的无OI曲线事后乘系数。

数据可用时间仍只有代理假设，没有历史发布收据。7个次日00:00观测至少需要单独考虑其测量/可用时刻，不能仅靠作者日期标签证明已知。

未解释的2024-03-11日值进入365天滚动与一天滞后后，在拟定完整窗口内可能直接影响 **2025-01-01 06:00至2025-03-12 00:00 UTC的280个可执行信号时刻**。这是结构依赖范围，不是已证实的成交或利润影响。之后信号即使不再直接依赖该行，先前的现金、数量、费用和持仓状态仍可能延续；不能据此宣称后半段账户已验证，也不另起一个更短窗口替代原窗口。
