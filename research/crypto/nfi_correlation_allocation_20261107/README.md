# A14 按已有多仓相关性调整 NFI X8 首仓

检验在已有多仓与候选币相关性高时，减少额外首仓，能否保留固定放大的收益并改善回撤。仍使用原生 NFI X8 的入场、加减仓和退出，只修改纯 Top Coins 多单首仓。取截至上一个已收盘 UTC 日的 30 个日对数收益，用 Pearson 相关系数的正值乘每个已有多仓的金额并加总。持仓量按上日收盘估值，待成交入场以挂单金额纳入。空头不抵扣。该重叠金额从零增至已实现账户资本的 30% 时，首仓倍数从 1.5 线性降至 1.0。缺价、零方差或非正的已实现资本回到原首仓。估计相关性用于分配仓位，它不是账户亏损上限。 [冻结协议](protocol.json) · [协方差与组合风险原理](https://onlinelibrary.wiley.com/doi/full/10.1111/j.1540-6261.1952.tb01525.x)
