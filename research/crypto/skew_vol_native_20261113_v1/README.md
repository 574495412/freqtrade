# 年度偏度与低波动：原生加密组合研究

本轮承接已完整淘汰的布林均值回归＋EMA趋势研究，检验不同的分布形状/彩票偏好机制。研究目标仍为在清楚且可比的完整账户窗口寻找更高收益；没有授权或进行部署、交易订单、运行服务修改。

## 来源、实现与适用范围

[Quantpedia原作者研究](https://quantpedia.com/skewness-lottery-trading-strategy-in-cryptocurrencies/)比较30日和360日偏度，年度模型月度做多低偏度、做空高偏度。只采用预先固定的360日方向和四分位，不根据本地回报反转符号、选择另一周期或挑分组。原文Premium代码未取得；`SkewVolPortfolio.py`是明确标注的本地Freqtrade `IStrategy`扩展，不是官方策略，也不是Coinmetrics原45币现货组合的复现。原文网页、取数日期和SHA在`source_receipt.json`。

输入从40币各自前361个完整日收盘计算360个简单收益；用总体三阶中心矩除以二阶矩的1.5次幂。常见样本调整对共同n=360只乘同一正系数，不改变截面排序。匹配对照用63个日收益样本标准差；同样要求361个价格共同支持。任一缺日/重复/非正价格/未定义方差都会拒绝，不删除币、填价格或缩短历史。800个币月、1600个因子值均由独立标量算术复核；120组实际输入截断/未来扰动与960项实际信号前缀检查通过。这是输入/时点证据，不是有效alpha认证或全面因果性证明。

只对这两个候选的20个截面做机制重叠检查，平均绝对Pearson为0.27005；没有声称比对所有历史因子、统计独立或新有效因子。低波动是已有机制的匹配对照。

## 原生账户合同

财务引擎是固定上游Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`的完整已校验vendor副本。实际Backtesting负责撮合、钱包、价格精度、保证金、资金费、持仓与风险退出；脚本只提供固定输入、标准IStrategy回调、无损缓存和只读观察。没有自建账户模拟器取代该引擎。

同一40币/顺序、USDT永续、1×逐仓，固定账户窗口2025-01-01 00:00至2026-08-31 23:00 UTC。引擎从前一空仓日开始，使原生首个日循环落在共同窗口开始；更早数据只用于365根预热，不能计作收益。所有20次决策只使用月初之前已完成日线。月1日退出全部旧仓，月2日00:00按冻结排序只发起一次新初始意图，每月10多/10空，保持到下次退出。这个一天现金间隔和原生顺序成交区别于原文即时再平衡，两个候选保持相同约定。

每个钱包首个当月入场冻结原生可投资资金/20的目标预算。下限超过预算则留现金，不能因最小订单自动放大某币；原生现金、舍入、撮合和清算仍约束实际成交。所有实际入场必须对应已确认源意图、冻结截面和预算，旧月份未退出持仓会阻止新一批。没有DCA、ROI或跟踪退出，保留原生−99%灾难止损和逐仓清算机制；50%是历史观察准入线，不是账户硬停机。

两策略分别实际跑1000和500 USDT，两档每边15/8bps费用与滑点代理，合计8账户。组合相加两个真正500钱包的同时刻NAV，不把1000账户缩放，不转账、不再平衡，可同币相反持仓、合计最多40个仓位，不是共享保证金对冲。原生5分钟detail，完整逐小时mark OPEN含浮盈亏、原生模型资金费和剩余退出费预留。2025和2026至8月的切片使用持续账户，不重置本金。

双成本冻结门槛：组合盈利、超过两条1000钱包单策略、逐小时最大观察回撤≤50%、每个连续日历切片盈利。未达到就保留失败，不改历史阈值或把某一年度当作新的独立成功窗口。
