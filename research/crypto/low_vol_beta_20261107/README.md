# 63 日低波动组合的 BTC Beta 配权

在已复现的 25 币 Binance USDT 永续低波动组合上，只改变多空腿的资金分配。低波动五币仍做多，高波动五币仍做空。每周用已经收盘的 63 个日收益估计各币对 BTC 的 OLS 斜率，分别对多空腿取均值。多头名义额占总敞口的比例为「空头腿 Beta / 两腿 Beta 之和」，事先限制在 25%–75%。腿内等权，无独立 BTC 仓位。借鉴多空腿 Beta 平衡思想，保留原低波动排序与自有账户合同。[预登记](registration.json) · [原 25 币账本](../low_vol_portfolio_20261107/README.md) · [Beta 平衡研究参考](https://www.aqr.com/Insights/Research/Journal-Article/Betting-Against-Beta)

1.6× 比较等金额与 Beta 配权。在模型每币 2× 初始保证金规则下，1.6× 周度目标约使用 80% 的起始保证金额度。另跑 2× Beta 组，并引用已封存的 2× 等金额对照。所有组都使用周一 00:05 成交价代理、公开结算资金费、原手数及容量约束和 30% 停机。目标总敞口只约束调仓时点，标记敞口可以随行情上升。账户是回顾性模拟。

## 25 bps 压力档

| 窗口 | 1.6× 等金额净收益 / 回撤 | 1.6× 动态 Beta 净收益 / 回撤 | 2× 动态 Beta 净收益 / 回撤 |
|---|---:|---:|---:|
| 2024 | +29.57% / 30.64% | +75.25% / 23.01% | +101.66% / 27.94% |
| 2025-01 至 09 | −4.19% / 30.11% | +23.59% / 28.67% | −13.57% / 30.02% |
| 原窗 2025-09 至 2026-08 | −14.28% / 30.95% | −8.28% / 26.22%（部分） | −11.13% / 30.17% |

1.6× 动态 Beta 组 2024 两档均通过该窗口门槛。13 bps 的净收益为 +79.75%、回撤 22.72%。较早 2025 两档均超过等金额和 1× 对照的收益，但回撤超出 25% 并出现模型调仓拒绝。原窗两档均亏损，且持仓经过两条公开结算缺口。2× 在 2024 的高收益伴随超限回撤与拒单，其他两段均触发停机。跨窗联合验收未通过。[完整账户结果](result.json)

140 个决策钟均用独立计算复核斜率，未出现配比边界截断，周度多头目标占比中位数为 63.45%。2024 压力档 1.6× 等金额组与 Beta 组共同运行的 328 个日收益观测中，实测 BTC 斜率从 −0.346 变为 +0.029。2025 年前段同档从 −0.547 变为 −0.015。原窗的共同运行只有 28 日，斜率从 −1.145 变为 −0.476，不能把估计配权当成实际脱离 BTC 方向风险。模型每周成交后按当前价格重新计量敞口，拒绝批次保留在结果。

## 固定起始配比诊断

主结果出来后，另登记在每个窗口把 1.6× 多头占比固定为首周当时已知的值，比较是否需要随周更新。25 bps 下固定配比在 2024、较早 2025 和原窗分别为 +40.95%、−8.74%、+11.08%，对应回撤 28.56%、30.31%、22.72%。动态配权在前两个窗口较好，在原窗较差。原窗固定组同样跨过公开资金费缺项，属于部分账面。诊断不替换原候选。[固定配比登记](static_check_registration.json) · [结果](static_check_result.json)
