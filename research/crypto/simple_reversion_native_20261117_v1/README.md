# 原始BB＋RSI均值回归：完整账户与固定组合均拒绝

本轮新增4个完成的Freqtrade原生模型钱包，共1000笔交易、2000个模拟成交、58,368个小时估值点。**原参数候选与4个固定组合全部亏损，没有找到更高可比收益；保留失败，不优化参数救回。**

## 来源、实际规则与本地配置

固定公开来源 [zodboy/freqtrade-simple-mean-reversion，16aa652f](https://github.com/zodboy/freqtrade-simple-mean-reversion/tree/16aa652f9db446e3738fea030e33ecc76be1e3ce)。4个源码树文件逐一核对Git blob与SHA256，`SimpleMeanReversion.py`直接由原生IStrategy加载，运行副本与原文件逐字节一致。源头是未有独立业绩证据的公开简单基线，不称作成熟获利策略。源文件和README声明MIT，树中没有单独LICENSE文件。

执行代码实际是：1小时close低于20期均值减2倍样本标准差，同时RSI低于35入场；15%单笔止损；无退出信号、无加仓；150根启动K线。源码RSI采用14期简单滚动涨跌幅均值，并非注释声称的Wilder平滑。ROI的720、1440、2880单位为分钟，即12、24、48小时；48小时后ROI阈值为−1%，**不是强制时间退出**。原生方法验证持仓60小时且亏10%时不会仅因时间达到而退出；实际最长持有602.583小时。保留这些代码行为，没有“修正”成另一策略。

作者示例配置为OKX、限价单、3槽；本轮沿用既有可比研究组的Binance、市场单、BTC/ETH两槽配置，保留源码信号、ROI、止损和启动规则。属于同合同原生验证，不是作者示例账户复现。

## 完整经济证据

所有新账户均在统一终点前自然平仓，期末没有持仓、未实现盈亏、退出费准备或终端强平订单。1000/20bp账户246笔交易，226次ROI退出、20次止损；13bp账户254笔交易，234次ROI退出、20次止损。两成本会通过原生ROI及现金路径改变后续成交，不能加回20bp费用冒充13bp账户。

20bp/1000账户毛已实现价格损益为−226.0002 USDT、已付quote费用349.8395 USDT，合计净亏575.8397 USDT；13bp账户毛价格损益−229.4810、费用256.3932，净亏485.8742。费用放大亏损，价格损益本身也为负。

独立脚本直接读取原生ZIP订单，逐笔重建数量、现金和每小时含退出费准备的净值，不导入候选计算器。四账户最大净值误差7.355e−8 USDT；完整期间与两个连续年度子窗的指标及所有组合均重新核对。`endpoint_components.json`拆开价格损益、费用与未实现项；`exit_audit.json`保留退出原因和持有时间。

引擎固定为Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`，核验595个原始模块文件。原生撮合、钱包、ROI和止损方法拥有收益证据；本地增加固定快照精度、只读观察及收据。该快照规则模型没有认证历史每时点真实交易所规则，不与40币永续或其他市场账户排名，也不解除OI默认版缺口。
