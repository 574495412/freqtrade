## 冻结账户合同

原40币及其顺序不变；USDT永续、仅做多、1×逐仓、unlimited stake、0.99可用资金比例、每个钱包最多6仓。完整连续账户从2025-01-01 00:00至2026-08-31 23:00 UTC；2025和2026截至8月的切片沿用同一净值，不重置资金。复用被观察过的历史与现时市场规则，有幸存者、版本和选择偏差，不是独立样本外。

两档每边成本15/8bps通过原生fee实现手续费及滑点等价预算，资金费另由原生计入。两个策略各跑实际1,000和500 USDT钱包，共8个冻结账户。组合只相加两条实际500钱包的同时刻NAV，总本金1,000；不缩放1,000账户曲线、不在钱包间转账、不再平衡、最多合计12仓，同币可重复持有。这不是共享钱包组合。

主周期信号使用各自原版周期，原生5分钟detail回放。账户观察为完整逐小时mark OPEN，包括浮盈亏、原生累计资金费及剩余平仓费预留；不是5分钟或盘中最坏回撤。终点原生强平另列，不混入共同边界排名。冻结门槛：两档组合均盈利、均超过两个1,000钱包单策略、每个连续日历切片盈利、逐小时最大回撤≤50%。该门槛不是账户硬止损；不根据亏损改日期、币池、参数或杠杆。
