# 平仓后的资金费对账

`observe_closed_funding` 在已注册的隔离驱动内扩展资金费步骤，沿用原整账户批次、来源事件账本、钱包检查点和 RD1 评估。平仓由原生成交记录与来源的终止成交共同证明。同批未平仓资金费继续由原生步骤处理。

来源账本在实际记账时刻记录现金或待结算成本。原生收益重算把新增信用或扣款归入最后一笔退出订单的资金费字段。这个归属是原生 P&L 的账务分配，事件的现金时点和订单原成交时点分别保存在原记录中。已计提资金费转为结算时，现金和待结算成本发生转移，收益增量为零。

批次先记录原生提交前后的完整状态。重试按两种已知状态恢复，原生变更范围限于资金费及收益字段。回溯到已完成账户检查点的事件由原账本拒绝。现有批次继续要求同一持仓的退出成交和退出后的资金费采用分别可核验的来源观察。

6 项合成隔离测试通过，覆盖扣款与返还、同批未平仓资金费、已计提转结算、提交前故障、提交确认丢失和回溯事件拒绝。测试使用临时 SQLite 和本地回执。运行登记、原始日志和最终源码校验见 `registration.json`、`test_run_002.log.gz` 和 `verification.json`。首次测试的夹具命名冲突保存在日志 001。

