# F1/F2 固定特征计算

`features.py` 实现冻结路线图中的 168h 动量与 24h 波动率缩放。只计算值和选币意向，没有交易、账户回测、网络、仓位下单或生产接入。

输入每行必须同时有小时开盘时刻、该小时最终收盘价及真实可用时间。`available_at` 由调用方提供可验证的观测证据，不能用 OHLCV 开盘时间、下载时间或假设发布延迟冒充历史接收时间。只接受 UTC 每日 00:00 的决策，意向执行时间为下一 5 分钟；实际是否执行仍由数据和 RD1 约束决定。

F1 需要连续 169 个完整小时收盘；F2 需要连续 25 个收盘形成 24 个小时收益，标准差 `ddof=1`。所需窗口缺失、重复、非正／非有限价格、未知／过早／延迟的可用时间均拒绝计算。不得回退到旧时刻、插值或提前使用未收盘 bar。F2 零波动拒绝新入场、低波动的乘数最多 1。

横截面只有所有固定成员可评估才选正值前三；并列按冻结币池顺序决定。缺失成员不自动删出币池，因子值必须属于同一决策时刻。选币不是风险批准；风险模块和执行集成仍待实现，`orders_enabled=false`。
