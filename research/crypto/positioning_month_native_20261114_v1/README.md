# 加密账户研究：交易者拥挤度的月度机会检验

**本轮完成12个原生完整资金窗口账户及一个实际500＋500组合的两档成本检验；没有找到合格的更高净收益方案。** 主策略15bps全段−26.26%、回撤56.38%，组合−29.58%、回撤46.70%。另外存在明确的历史指标缺口，不能把这些条件账户当成输入完整的源研究复现或已接受alpha。

当前范围为加密 BTC／ETH／SOL。港美股工作不计入本轮成果。没有下单、部署、模拟盘或运行服务修改、提交和推送；整体目标仍未完成。

## 规则来源与本地资金合同

[TradeWize原始文章](https://tradewize.io/blog/how-to-read-the-long-short-ratio)按日末快照、各合约自己的365日历史、低10%状态观察后续30日价格。作者明确是单交易所、样本内、毛事件研究，未计费用和资金费，也没有执行资金策略。其事件均值不是本地账户收益。

原文未给出完整交易规则、并列值和当前值是否进入参考窗的实现。本地在财务结果前冻结：当前值对严格之前365个日历观察计算中位并列百分位，≤0.10触发下一天开始的30日机会；同币种机会重叠取并集、不叠加。每币种有1/3目标槽位，未活跃槽位持现金，其他币种不再分配这部分预算；账户开始前的机会不继承。

主信号使用全体账户数量多空比；控制使用大户持仓规模多空比，同样的阈值、周期与交易合同。没有把大户账户数量冒充持仓资金，也没有将高尾反向做空。三个指标只是不同测量，不宣称天然独立alpha。辅助原生输出的 `source_signal` 保留真实排名NaN；`source_volatility`只是旧运行器接口所需的0占位，未使用或称为波动率因子。

日末精确23:55快照按“观察时刻＋5分钟”代理可见，在D00生成信号，原生1h下一行D01执行，5分钟detail处理成交。这个代理和档案SHA不能认证原始传输、首见或历史修订可知性。日度数量目标为0.99×实际预算净值的权重部分，使用原生现金、精度、最小交易额、费用、资金费和调仓。无法成交的小变动保留跟踪差异，不放大最小单；实际500钱包不能由1000账户线性推算。

统一3倍cross是保证金配置，不是3倍名义敞口目标；原生−0.99保证金止损／清算仍生效，因此机会可能被止损提前退出，下一次日度信号再按冻结规则处理。恒定敞口控制也包含这些约束，不是无止损现货买入持有。0.99是调仓目标，不是所有时刻的硬上限；全矩阵最大实际mark名义敞口约1.054倍净值。30%是历史验收门槛，未伪称硬止损。

## 官方档案完整取得，但观察与排名并非全部已知

实际取得并独立SHA256核验2024-01-01～2026-08-31的 **2922份官方日档**，含612份复用的已核验BTC档案及2310份新增档案；原始841146行全部保留在ZIP。官方校验和、实际文件哈希、币种与日期逐份核对，不从其他交易所或近邻时刻替代。

2922个声明日槽中只有2919个精确有效日末快照：三币种的2024-02-16均缺23:55。严格365个此前观察令2025-01-01～02-16每币种各47个排名未知，即主信号141个coin-day、持仓控制另141个。不是观测为0，也没有降低最少观察数、向前填值或取较早快照来补齐。

冻结策略明确规定未知时不新增机会，已知机会到期照常；本例未知期在窗口开头，两个信号均没有继承的机会，实际持现金。资金账户仍覆盖整个原窗口，**其收益只证明这项显式缺失处理政策下的账户表现**。不能把未知期现金效果归因于因子择时；恒定控制未使用同样的初始缺失掩码，因此即便少亏也不是缺失影响已隔离的alpha证明。输入完整准入仍为否。

其余盘中原始缺行／缺值不被宣称齐全；本假设只选择精确日末观察。完整资金窗口的OHLCV、mark和资金费是另外核验的合同。当前原始日末字段全体账户与大户账户的608日Spearman分别约BTC0.992、ETH0.891、SOL0.976（精确值以 `input_correlation_diagnostic.json` 为准）；这是原始输入的限定描述，不是跨Registry的因子去重。

## 原生执行和独立审核

固定 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`，595个原始文件哈希及无额外Python核验。实际链为 Configuration → StrategyResolver／IStrategy → DataProvider → Backtesting → Trade／Order／Wallets → 原生ZIP。新 `freqtrade/data/binance_positioning.py` 是显式本地历史输入扩展；没有另造资金引擎或将外算曲线注册为原生结果。

单合约自身历史状态驱动组合，未冒充已接受横截面因子：Registry、factor_analysis、Vibe SQLite bench新增均为0。Freqtrade原生ZIP与本地冻结研究登记的含义分别列示，未跨引擎制造bench证明。

12个进程均退出0，12份实际ZIP、有效配置、权重和指标、175104个逐小时净值、7296个日度资金预算核对。独立读取原生成交重算143个含强制退出的持仓记录、944笔订单和663次成交调仓；三币种完整5472个8小时资金费事件的持仓归属检查通过。最大净值误差约4.19×10⁻⁸ USDT，资金费误差约3.55×10⁻¹⁵ USDT；预算净值差约2.27×10⁻¹³ USDT。

16项输入／时钟／机会测试通过；实际原生策略路径另核验3654个排名标量单元、18组真实数据截断／未来扰动，以及机会到期和小时映射。5472项到期检查含常量控制重复暴露的同一机会状态，不能当独立统计样本。原生回调warning/error保护均未发现被压制异常。代码、数据时序、资金正确性不等于经济有效。

净值采用统一小时原生事件处理前mark OPEN，包含浮盈、已归属资金费与剩余退出费准备；不是盘中最差回撤，也不以终点强制退出净值替代统一窗口。15／8bps是每侧聚合成本情景，不认证真实订单簿冲击或私有交易所资金费结算。精度、最小额和杠杆来自冻结市场快照，未认证每个历史时点的规则变化。三币种是来源选定的已存续样本，不是全市场无生存偏差主表；方法发布及本地选择均晚于所检验历史，不能称独立样本外。

## 保留的工程失败与后续边界

首次下载器一个future抛错后停止收集，但线程池仍执行排队任务；通过收据1537条、磁盘持续新增的实际状态与控制流确认。只停止这个自有下载进程（退出143），保留原脚本、记录和字节；修成逐项成功／失败记账后，仅恢复已校验输入，342份孤立成功文件重新对官方校验和验证。最终2922份通过、未解决下载失败0。初次异常的具体原始栈未取得，不虚构其为某个HTTP状态。

磁盘紧张时仅将已终结自有运行的逐字节相同缓存／证据改成硬链接；未删行情、历史失败或其他项目数据。旧HMM全部封存哈希再核验一致，本轮缓存同样保留。金融始终单worker，3GiB RSS／1小时保护，每次启动前至少2GiB空闲；没有降低保护来补完账户。

本地固定策略同时失败于全段收益、回撤、跨年度稳定性／周期数量，且源指标完整性仍不足；不进行方向翻转、阈值、币种、费用、持仓周期或年份挽救。后续应先审查不同公开完整规则及可准入输入；任何欲将少亏解释为alpha的比较，还须增加原生可用性匹配控制及独立验证。本轮不批准部署，也不否定所有多空比研究。
