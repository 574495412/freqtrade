## 来源规则与数据

固定第三方[GitHub提交](https://github.com/VernonCM/bot-volume-profile-bybit/tree/b213ff69f18bc0907249cbc8a0ea20146ccd199c)，读取`config.py`、指标、两状态机及回测器；来源是Bybit，本地明确迁移到Binance BTC永续，不复制其2021年以来的结果或四组收益。未取得该树的许可证声明；本地独立编写数学／状态实现，来源纯指标和纯决策函数只作隔离核对，未执行第三方资金回测器。

每个完整UTC日由96根十五分钟K线形成100个等宽价格格；每根K线的基础币成交量均分给它触及的格子，**不是按真实逐笔价位分配，也不是按价格重叠长度加权**。零振幅K线有独立边界规则。POC在并列最大时取最早格，从该格向相邻更大成交量方向扩张到至少70%，邻格相等时向上。这个局部实现不等同于简单的上下分位数、TradingView全部算法或订单流delta。

前一完整日的POC／VAH／VAL固定供次日使用。量过滤均值只含前20根十五分钟K线。该分布不能认证当前持仓成本、主力筹码、挂单深度或真实多空主动性。[作者文章](https://criptomatiko.com/volume-profile/)也说明它是K线近似；其收益宣传没有计入本地证据。

原有五分钟、小时、日线、MARK及资金费文件按旧SHA核对并无损链接；从2024-12-30开始的175,680根真实五分钟K线逐三根聚合成58,560根十五分钟输入，原生FeatherDataHandler写入、`load_pair_history(fill_up_missing=False)`回读精确一致。没有插值、补零、改变旧输入或新增行情请求。610个输入日含两天预热，资金窗口仍为608日。

## 来源状态与原生执行集成

突破：平仓状态下，收盘越出昨日日价值区且成交量≥前20均值1.5倍才首次发信号；区间内的已处理平仓K线才重置闩锁。止损在价值区另一端，目标按信号收盘到止损距离设1R。回归：记住最初越界的价值区及方向，跟随越界极值；超过32根后失效，回穿旧边界时反向入场，止损在极值，目标为原价值区另一端。不是每天强制重置；回归参考区可跨日保留。

**有实际原生持仓时不推进状态机。** 本地新增`freqtrade/optimize/volume_profile.py`显式BACKTEST子类，在原生`check_for_trade_entry`分类边界读取实际`LocalTrade`，再让未改的原生循环决定入场、五分钟明细、止损、止盈和退出。回调只取原生DataProvider已完成十五分钟输入，明确校验`input_date＋15分钟＝当前时刻`；未使用当前未完成K线。初始空仓，首个决策为窗口第一根K线结束后，无同一主K线退出后再入场。

最初钩子放在较晚的`backtest_loop`，会让首次动态入场错过原生明细缓存构建；**在资金运行前**移到分类边界，旧源码及测试记录保留。模型、风险参数及经济窗口没有变化。没有改固定上游树的595个文件，也没有用独立账户模拟器替代原生循环。

主账户实际经Configuration、StrategyResolver／IStrategy、DataProvider、本地显式子类及上游Backtesting、Trade／Order、Wallets、保证金／资金费和原生ZIP执行。`register.py`只是本地冻结计划，不是API登记代替backtest，也没有伪造Vibe SignalEngine或SQLite bench。这里是单BTC状态型策略，未做截面因子选择，新增Registry／factor_analysis／Vibe bench均0。

## 风险、成交与来源差异

来源固定价格风险预算为当前原生平仓现金的1%，以实际入场价到来源止损的距离计算数量，最大入场名义额约3倍，另受99%原生可用保证金约束。固定3倍isolated配置、最多一仓、无DCA，原生数量步长／最小金额及双侧费用保留，不向上凑最低单。**1%是计划价格风险，不是含费用、滑点及跳空的保证损失上限**；3倍是入场目标约束，不是持仓期间固定敞口。各账户实际小时最大毛敞口／NAV约2.93～2.99。

每侧15／8bp作为固定合并成本写入原生fee，资金费单列；不是盘口深度或可成交冲击认证。普通入场避开00／08／16UTC整点，状态仍更新并保留被时钟阻止的意图；机械退出始终有效。

原生止损／止盈在入场主K线内也有效，来源简化循环先检查退出再入场、未保护入场K线。原生使用五分钟明细及不利跳空、价格精度、费用、资金费和清算；原来源的入场佣金仅减少数量、没有在账户现金中完整扣除，本地没有复制它。故此为明确迁移的原生政策，不是来源账户曲线复现。

实际185次退出发生在入场十五分钟内。原生某些固定绝对custom stop会标记`trailing_stop_loss`，这不代表添加了另一个自选跟踪算法。全部来源止损与最终原生绝对水平的差不超过一跳0.1USDT；独立重建2,916笔止损成交，最大价格误差0。原生入场第一分钟的custom-stop特殊成交公式已核查，本批触发次数0，不能因其存在而声称本批发生。止盈触价、实际价格及逐笔风险预算也逐项核对。
