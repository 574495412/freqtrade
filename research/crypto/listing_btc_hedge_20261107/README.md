# A07 新上市空头与 BTC 多头对冲

检验 BTC 多头能否抵消上市空头的共同市场风险，并改善扣费后净收益。按 A05 的首日成交额、入场时钟、72 小时目标和风险合同回放。每 1 USDT 新上市合约空头搭配 0.5 USDT BTC 永续多头，两腿共用原单笔预算。单仓合计最高 25% 净值，最多三仓，1×。同空仓对照保留 2/3 的每仓及组合空仓额度，使用同样的原版空头规则。完整空仓组保持 A05 原规则。 [经济规则登记](registration.json) · [共同风险因子研究](https://www.nber.org/papers/w25882)

BTC 输入包含 281,952 根五分钟成交和标记价 K 线以及 2,937 条逐笔公开资金费。两腿独立扣手续费、滑点代理及实际公开结算费率，BTC 盘口容量在重叠仓之间共享。部分退出时同步缩减比例，单腿异常越过模型全损线时，另一腿排队退出。该成交模型使用下一根五分钟收盘及成交额容量，缺少两腿同步可成交与交易所强平证明。 [BTC 数据登记](btc_registration.json) · [Binance 公开数据](https://github.com/binance/binance-public-data)

2024 压力成本下，多数改善来自空仓额度降低。BTC 组比同空仓组只多 0.54 个百分点，仍亏损。2025–2026 连续账户两档均触发停机。2026 空仓起跑压力组比同空仓组少赚 7.95 个百分点，回撤还多 0.75 个百分点。BTC 腿在该账户扣费后贡献 −75.57 USDT。该腿贡献是已成交路径的拆分，退出规则及后续仓位变化也会影响账户总差额。2026 独立重启和连续窗复用同一批行情。
