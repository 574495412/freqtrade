# 固定因子账户补充核算

该目录只读取已保存的成交、净值和行情；不运行策略、不增加金融账户、不改变参数。完整跨窗口策略结论须等当前合约长窗口六账户批次完成。

- `spot_curve_audit.json`：12 个现货账户、1,073,088 个 5m 时点的现金、持仓与净值重建。最大净值误差 6.261e-8 USDT；此前只独立核对了全时点敞口和期末净值，本次补齐整条净值曲线。
- 重建曲线与观察曲线的最大回撤数值差上限 4.54224435842e-11；失败收益没有改变。
- `futures_short_account_details.json`：6 个合约短窗口账户的逐笔持仓年龄、终态未平仓、DCA、敞口、风险状态与固定成交路径成本分解。人工期末退出不计入自然结束，未平仓保留退出成本预留。
- `audit_futures_short_details.py --check`：重新计算六份明细，与保存输出完全相同。该检查是结果核算，不是策略确定性重跑。

复核命令：

```sh
.venv-paper/bin/python -B research/crypto/factor_cost_review_20261106/audit_futures_short_details.py --check
```

`audit_spot_curves.py` 只允许首次写入新结果，拒绝覆盖已保存的证据。两项核算均验证登记和输出哈希，使用原成本、原成交、原价格与原生资金费模型。

现货采用已声明的 5m OPEN 条件估值，合约采用冻结 mark 和原生模型资金费；这些核算不能证明历史盘口、实际成交容量、首次接收时间或真实资金费/成交排序。`RD1_applied=false`，无独立留出或上线资格。
