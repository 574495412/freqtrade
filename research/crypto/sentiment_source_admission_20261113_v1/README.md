# 情绪开关来源准入：暂不进入原生财务回测

本轮审查新的信息来源机制：恐惧贪婪指数作为小时趋势策略的入场、仓位及退出开关。结果是**拒绝所审来源的收益证据，并非证明情绪因子无效**。没有新增Freqtrade账户或组合收益，没有把第三方账本、注册或源码检查计作原生回测成功。持续更高收益目标仍未完成。

## 固定来源与规则

[trippleyay/fg-regime-switcher](https://github.com/trippleyay/fg-regime-switcher/tree/9e142d1412a43600598e742460b111ccfb7da01b)固定在`9e142d1412a43600598e742460b111ccfb7da01b`，MIT。12份原始文件逐字保存，URL、SHA256、下载时间见`source_manifest.json`。只调用其中的纯指标、合并和条件函数；没有执行其独立财务模拟器、CLI、插件、技能或连接账户。

来源使用BTC、ETH、BNB、CAKE现货，1h，最多2仓；EMA20上穿50、RSI14>50、收盘高于EMA200且情绪>25入场。情绪26–49半仓，50以上整仓，25及以下退出；EMA下穿或ATR跟踪边界也退出；同时候选按ROC10×20期相对成交量排名。上述是来源规则，不是已经通过本项目准入的新有效因子。

实际源码的跟踪价是`max(旧边界, 当前收盘 - 入场时固定倍数 × 当前ATR)`。倍数由入场时的情绪决定，持仓中不会因为后来进入极度贪婪而自动由2变成1.5；这也不等同于“最高收盘 - 当前ATR”。若后续移植，不能只读README后默默更换此语义。

## 已复现的证据问题

1. **反向填入未来值。** 精确调用原函数`merge_fg_onto_bars`：早期一天没有情绪观测、下一天观测分别为20和90，仅改变这一未来值就改变了此前24小时的输入。截断到早期一天时则全为未知。原因是源码合并后调用`ffill().bfill()`。这是实际函数的因果失败；尚未证明作者发布账户中有多少笔受到该路径影响。
2. **实际早期交易不满足有限RSI门槛。** 独立取得并按官方SHA校验2020-01-01 BTC和ETH小时现货档案；原源码只从窗口起点加载，没有预热历史。两币第二根小时线上涨，源码把零平均下跌替换成NaN，使RSI未知；`if RSI<=50: reject`却放行NaN。实际纯函数接受两笔，且作者发布的最早BTC/ETH交易就在该小时、价格等于该小时收盘。不能把未知RSI叫作已满足RSI>50。详见`function_checks.json`及2份官方档案。
3. **同小时收盘决策和成交。** 原始价格索引来自小时开盘时间；独立事件循环读取该小时完整OHLCV后立即按其收盘价建仓/平仓。最早两笔公开成交分别为7216.27和130.64，与官方同小时收盘一致。这是同收盘执行假设，不是原生下一根开盘成交，也没有报价/可成交证明。没有另行断言所有同收盘策略必然不可能执行。
4. **发布账本不是完整小时日历。** 起止2020-01-01 00:00至2026-05-01 00:00 UTC，应55,489个小时点，实际55,457个，缺32小时、无重复。32个内部缺口全部在2025年之前，不把它们说成当前比较窗内缺数；当前2025-01至2026-08比较窗则因作者发布结果止于5月而有2,951个终段小时未覆盖。缺失原因未知；未把这些小时零填、前填或删除持仓来修复收益。缺口本身不能证明其报告回撤一定被低估。完整缺失时点保存于`source_artifact_audit.json`。
5. **收益是第三方无成本现货结果。** 871笔交易的价格差×数量、公开PNL、总账终值和摘要四舍五入一致；毛收益371.67%、观察到的时钟回撤33.15%可算术对上。这只证明已发布文件内部一致，没有重跑其全历史市场输入，更不是本项目含成本完整账户收益。源代码没有手续费或滑点；此处也没有凭空补费后声称得到了新的净收益。

`audit_source.py`保留独立峰值遍历、逐笔PNL复算及精确源码函数夹具。`function_checks.json`的日内发布时间夹具另证明：若日值在12:00才发布，按日期合并会把它用于此前12小时。这是接口能力缺陷演示，**不是已经查明CMC历史实际在12:00发布**。

## 数据口径仍未满足

来源在2023-07拼接两家指数，当前完整比较窗2025-01至2026-08按其规则需要CMC历史序列。[CMC方法](https://coinmarketcap.com/charts/fear-and-greed-index/)含前十币价格、BTC/ETH隐含波动率、期权Put/Call、稳定币供应比及自身社交指标；[Alternative.me方法](https://alternative.me/crypto/fear-and-greed-index/)含BTC价格/波动率、成交量、Twitter关注、BTC市占率与Google搜索。0–100相同量纲不能证明相同因子或相同门槛语义。Alternative.me还有当前暂停的调查组件；没有取得逐期组件权重的历史认证。

本轮匿名请求源码所用CMC Pro历史端点返回HTTP401、`API key missing`，没有取得该端点的完整历史输入。这里只陈述已尝试路径；不推断全网没有其他官方公开历史路径。不搜索或动用任何现有私钥，不用发布的`equity.csv`中fg列冒充独立原始CMC数据，不静默换成Alternative.me后声称复现了原策略。两家方法网页、最新Alternative.me两条响应及CMC失败响应原样保存于`provider/`，均有哈希收据。

Alternative.me当前接口的观测时间字段和下一次更新倒计时，不足以认证所有历史值的首见时间、未修订状态或历史分发延迟。即使后续做“滞后一整天”的明确代理实验，也只能称本地条件模型；不能自动升级为独立可用性证明。该指数部分输入直接来自价格/波动率，因此也不能仅凭名称宣称与既有价格因子独立。
