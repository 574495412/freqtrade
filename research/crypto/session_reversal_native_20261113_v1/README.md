# BTC/ETH 分时段反转：12个原生账户完成，本地平仓重开方案失败

**本轮没有找到合格的更高收益组合。** 12个冻结账户均完成实际Freqtrade回测，逐小时完整净值和成交现金复核通过；每边15/8bps下，两个实际500USDT钱包相加的来源规则组合分别亏损88.12%/57.58%，回撤88.26%/64.44%，落后被动组合且未通过固定门槛。保留所有失败，不进入运行服务或部署。

本地实现每12小时平仓、隔5分钟重开，同方向也收费。这不同于论文只按方向变化计算换手成本；因此**淘汰的是该可执行平仓重开方案，不是声称论文原样复现失败，更不是否定整个时段反转机制**。这个执行差异和市场差异在任何财务结果出现前已经冻结。更接近来源、同时遵守原生现金和数量约束的持续持仓/部分调整方案仍需另行实现与验证。

## 来源、实现和时点

[Wu/Pinsky论文](https://www.mdpi.com/1911-8074/19/9/692)的作者代码固定在[`5693993e108f2b3668bd21b1dd36ae31f79d8fcd`](https://github.com/wzf01195010-png/Crypto-day-night-effects/tree/5693993e108f2b3668bd21b1dd36ae31f79d8fcd)，MIT。来源选择过300种组合，BTC最优规则在其训练留出中不稳定，且校正后的统计检验未支持可靠超额收益。保留这些限制。原始代码和清单在`source/`、`source_manifest.json`；未执行其独立账户计算。

固定来源符号：BTC日段08–20UTC、夜段20–08均取前一天同一时段收益的相反方向；ETH日段05–17反转、夜段17–05做多。不是用刚结束的异类时段收益。方向和小时没有在本地结果后选择。论文原市场是Kraken USD现货；本地使用Binance USDT永续，原生下一根5分钟开盘，均披露为本地适配。论文选取2016–2025，故本轮重叠历史不是独立样本外。

同期审查的[Concretum时段文章](https://concretumgroup.com/seasonality-in-bitcoin-intraday-trend-trading/)讨论周内趋势效应，但未公开文中高频模型集合，不能凭其毛夏普主张反推完整策略或宣称已复现。旧九周期Donchian属于另一份多日研究，不能把它当作此高频集合。本轮X、YouTube、抖音检索没有提供可核验的完整策略规则，不声称已观看或完成其收益验证。

账户由固定上游Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`的`Backtesting`、原生钱包/撮合/资金费和`IStrategy`接口运行。`SessionRules.py`是本地策略，不是上游自带盈利策略；支持脚本只负责输入、冻结、存储、只读观察和审计。没有替换账户引擎，没有把注册、第三方结果或外部模拟器当作本轮收益。

## 冻结的完整账户合同

- 连续2025-01-01 00:00至2026-08-31 23:00 UTC，共14,592个逐小时点/账户。2025与2026年切片沿用同一账户，不重置本金。
- 每币每策略独立500USDT，1×逐仓、最多1仓、0.99可投资资金。正常native5m撮合；无ROI/DCA/追踪止损，保留99%灾难止损及原生强平。50%历史回撤晋级线不是实时止损保证。
- 来源规则与TimedLong均在边界平仓，下一根5分钟开盘重开；TimedLong用相同输入掩码和时点恒定做多。PassiveLong从最早合法native时点进入并持续持有，保留终点强制关闭。
- 单边总成本代理15/8bps，通过原生手续费参数表达，另计原生资金费；不是精确盘口滑点模型。只有同一政策的BTC500+ETH500相加成1000，期间无跨钱包转账或再平衡，不缩放1000账户、不平均交易收益。
- 排名使用同一终点的盘前小时mark净值，含浮盈亏、原生资金费及剩余退出费预留。原生末尾强制平仓余额另列；小时回撤不等于盘中最差回撤或实际可成交清算值。

协议原件在`protocol.json`、财务输入/代码哈希在`plan.json`。只有来源组合同时在两档成本盈利、两个持续年度切片盈利、回撤≤50%并超过两个对照，才过数字关；数字过关也不会消除来源选择偏差或建立实盘资格。本轮两档均失败。

## 实际组合结果

下列均为两份实际原生钱包相加的净收益 / 最大小时mark回撤。

|单边成本|分时段来源规则|相同时段恒定做多|被动做多|
|---|---:|---:|---:|
|15bps|−88.12% / 88.26%|−91.56% / 92.09%|−26.75% / 62.35%|
|8bps|−57.58% / 64.44%|−83.95% / 87.15%|−26.63% / 62.31%|

来源组合在8bps的2025年曾盈利5.08%，但持续2026年至8月亏损59.63%；不能选择这个盈利切片代替完整窗口。15bps两年度分别−57.70%/−71.91%。与相同时段恒定多相比少亏，仍不足以超过被动持有或通过盈利/回撤关。两个来源腿日净值收益相关约0.17/0.20，低相关没有转化为合格组合。

15bps来源BTC/ETH两腿分别−87.28%/−88.95%；8bps分别−73.77%/−41.39%。此处不将“少亏”、较低相关或完整进程退出0包装为有效alpha。

## 资金约束与证据范围

15bps来源BTC的1216个非零计划时段只实际成交1055次，161次因账户亏损后不满足原生最小stake/数量而未成交；没有补钱或最小金额向上强加仓。两个高成本TimedLong账户分别有407和324次未成交意图。8bps四个timed账户均实际成交1216次。每个未成交时点已用**实际此前已平仓收益**、下一根真实开盘价、冻结最小stake预留与数量阶梯独立核对；这是支持审计，不是另建收益模拟器。

12/12进程退出0、12份原生ZIP、175,104个完整小时净值点均已检查。实际原生指标与事先预检逐字段一致；逐笔原生导出成交现金按Decimal复算；净值端点和最大回撤独立峰值遍历一致。每个真实入场的方向、开盘价、数量、11小时55分自然持有及退出原因均核对。PassiveLong四账户各1笔持仓，终点强制退出不算自然退出。

输入5分钟日历无缺失/重复，全部OHLC有限且价格为正。两币1h收盘与对应5分钟末根收盘逐个一致；6组实际native策略共7296个边界与作者纯session/sign函数一致；3截止点×6组真实前缀/未来价格扰动通过。只执行纯指标/会话函数，不执行来源账户引擎，也不等同于完整官方lookahead认证。

另取40份官方月度资金费档案并验证SHA，BTC/ETH各1824条完整8小时时槽，费率与本地原生输入一致。本轮没有旧AXS/TRB时槽问题。但这不认证实际账户付款，也不能确定08:00同刻先成交还是先结算；本地原生小时资金费归属是模型合同。

原生预检第一版缺`user_data_dir`，保存失败后单独v2补齐诊断配置，未改财务计划/策略。事后指标审计先因ms/us时间索引dtype不同失败，统一成ns后逐值检查，未删除、补填或改变任何时间点。原始失败分别在`preflight_failure_v1.json`和`analysis_failure_v1.json`。
