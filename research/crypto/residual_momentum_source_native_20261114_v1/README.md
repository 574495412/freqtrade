采用锁定评估代码的参数，不再搜索作者的十二种形成／持有组合：八币等权简单小时收益作为共同市场，720 小时滚动 covariance／variance beta（最少 684 行），逐小时收益减 beta×市场，再累计 336 小时残差（最少 319 行）。实际代码**没有减回归截距，也没有按残差波动标准化**，不从 README 的回归表达式补造这些步骤。市场包含每只资产自身。

这与旧的 [A16 相对下跌后修复](../residual_recovery_basket_20261107/README.md)有不同方向、共同市场与时钟；旧 A16 是辅助历史账户，不追认为本次 Freqtrade 回测，也不翻转旧失败。数学区别仍不证明信息独立。

## 原生所有权与时钟

固定 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`，重新核对清单内 **595 个原始文件**。本地新增 `freqtrade/data/residual_momentum.py`；真实 `StrategyResolver → IStrategy → DataProvider` 调用它计算特征。该模块及隔离 Registry 桥是本地扩展，不能称为上游自带的残差策略。

账户目标窗口保持 **2025-01-01 00:00～2026-08-31 23:00 UTC**。固定每 168 小时一次，锚定 2025-01-01，不按年重置相位。D 日 00:00 的信号只用截至 D−1 小时那根已完成 K 线，原生指标映射已逐项核验；若晋级，原生一根 1h 延迟对应 D 日 01:00 执行。

预测标签为 D 日 01:00 原生 OPEN 至 168 小时后 OPEN 的简单收益。只取终点仍在共同窗口内的 **86 个非重叠标签**：首个决策 2025-01-01，最后完整决策 2026-08-19。末尾不足一周的标签不计入预测分析；这不是把完整账户终点改到八月十九日，资金阶段仍须跑到原定八月三十一日。

源代码的未来整周收益最后可能全缺失，但随后 `.sum(axis=1)` 会把整行缺失聚合成 0，`dropna` 也不会剔除。独立合成聚合检查保留在 [source_tail_diagnostic.json](source_tail_diagnostic.json)。本地不把不成熟标签当零收益。作者用均值乘年化期数展示的 return 也不是账户 CAGR；作者的“锁定／OOS”说法未获得本地独立时点认证。

## 输入、正确性与去重证据

旧每币 15,336 个小时从 2024-12-01 开始，不足以完整预热此模型。新增八份 **2024 年十一月 Binance 官方 1h 月档**，逐份核对官方 `.CHECKSUM`，经真实原生 Feather handler 存取，现为每币 **16,056 行**。原八份父文件 SHA 保持不变；原 15,336 行所有数值逐项精确一致。新文件按原生 handler 要求将 volume 整数类型规范成浮点，不能把数值一致说成新文件字节或 dtype 完全一致。

首次 ADA 存取因上述 dtype 断言拒绝，旧源码、失败日志、已保存 ZIP 和输出均保留。`prepare_v2.py` 检查已存结果后恢复缺少步骤，没有覆盖旧数据、丢弃价格或进行资金回测重跑。

**18 项组件检查通过**，包括小时缺口／重复／无效价格拒绝、源最短预热、未来扰动、截断、价格尺度不变及输入类拒绝 live／dry-run／非诊断模式。生产新模块完整 Ruff、研究脚本语义检查通过。

原生实际特征与源 notebook 四个纯数学单元的 **366,384 个有限 beta／残差／信号值精确一致**；没有执行源组合／成本引擎。独立 `math.fsum` 对三个实际时点、八币重算每个分数所需的全部 336 个滚动残差，核对 24 个分数，最大误差约 **2.64×10⁻¹⁶**。三个真实数据边界的截断／未来扰动通过，另核对 **256,896 个实际原生指标映射单元**。这些是特征正确性和局部因果证据，不是完整官方 lookahead／recursive 认证或盈利证明。

同日期截面 Pearson 平均绝对值：对八币原始动量 **.8883**、八币低波动 **.3359**；对旧六币 EDGE／Amihud／LowVol63 的共同六币分别为 .3997／.3300／.4002。五个检查面板均有 86 日支持，无>.99 重复；只覆盖这些可用面板，不是全部 Registry 去重或独立 alpha 证明。与原始动量的较高相关也保留。
