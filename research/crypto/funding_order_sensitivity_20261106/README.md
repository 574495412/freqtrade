# 封存永续账户的资金费时序敏感性

对原 12 个永续模型账户重新核对完整 5m 净值。封存的成交、费用、数量、标记价、风险状态和入场退出记录是共同基准。只复算资金费现金贡献，策略和账户执行数均为 0。

1. 原口径复算使用小时键及原生模型的含边界累计法，1,073,088 个 5m 净值点对原曲线的最大误差约 0.000000190 USDT。
2. 时钟诊断只把资金费索引从小时键换成公开结算毫秒，保留原含边界累计法。期末权益与原值的最大绝对差约 0.041 USDT。
3. 逐事件一次入账的诊断沿用冻结小时标记价。对公开结算同毫秒的成交分别比较先结算和后结算。另取从名义小时到公开结算毫秒之间固定成交可能产生的持仓上下界，并按费率正负计算逐事件现金上下界。该组曲线在公开事件后的第一个 5m 观察点纳入资金费。

在上述已登记核算中，期末权益与原值的最大绝对差为 0.166746 USDT，整条净值路径上的最大绝对差为 0.657913 USDT。F1 四个账户的期末权益在这些口径下一致。12 个账户在有利边界下均亏损，因子账户最接近盈亏平衡的是 F2 短窗压力，净收益上界仍为 -1.2192%。
