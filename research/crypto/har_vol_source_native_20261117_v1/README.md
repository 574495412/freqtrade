## 来源、机制与扩展边界

固定来源[waelsabri11/intraday-volatility-research，80059675020e](https://github.com/waelsabri11/intraday-volatility-research/tree/80059675020e299e46eeed2a6a86b4a2eea1a9a7)。作者明确将其定位为波动率预测/风险控制研究，并未宣称盈利策略。17个源码文件逐一核对Git blob与SHA256；没有复制作者回测收益或执行其账户模拟器。

使用原始daily_features：5分钟已实现方差及1/7/30日对数HAR特征。HAR为带截距OLS、训练残差Duan smearing；Naive直接用当前RV预测下一日。保留730个日历位置的初始阈值、每30日重拟合、扩展训练窗。首轮实际700条有效训练样本，最终1390条，每币24个拟合窗口；“730”并非承诺730条有效样本。

已知特征与未来目标的资格检查在原生接口中分开：训练仅用原点之前的行，其标签不晚于拟合原点当日收盘；预测资格只看已知特征，不看尚未观察到的次日目标是否存在。作者原离线共同评估掩码含未来目标，不能原样当交易开关。原生接口是本地扩展，不称其为Freqtrade上游功能；在共同已成熟样本上，预测与作者原始OLS/Naive/滚动评估数学一致，保留训练日历，未重调参数。

历史从2022-10-01开始，作者源头从2019年开始；本轮是同方法、不同初始化的本地研究，不是作者完整报告复现。源码树没有独立LICENSE文件；未作部署或分发资格结论。
