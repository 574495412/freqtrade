## 研究选择

当前可取的第一对照是原版与一个只限制非 Top Coins 仓位继续加仓的版本。保持入场、币池、杠杆、成本和退出逻辑。沿用既有风险研究的可检验思路，首仓之外最多追加两次，累计追加额不超过首仓。检验减少长期资金占用后，新增机会能否覆盖少加仓导致的机会损失。两空槽限制保留为集中度对照，禁用 `562` 和按近期赢家换币缺少支持。较早版本的全局风险约束降低了回撤，也降低了收益，说明控风险与增收益必须分开验收。[此前有界加仓研究](../../../docs/crypto-nfi-risk-cap-20261024.md)

经济比较前仍需解释 X8 现货、永续官方前视检查各三个退出时点异常。固定相同币池、相同状态和前缀，在逐笔退出与加减仓层面复核，并分开验证 800 根预热的信号稳定性。经济对照需使用同窗口及成本、完整净值和期末持仓，要求扣费、滑点代理和资金费后收益高于原版，且观察回撤与尾部暴露无恶化，再用登记后未见样本验证。本轮完成了账本归因，新增候选账户为 0，收益提升尚未证实。[前视诊断原始解释](../../../docs/research-20261105/crypto-wide-comparison-20261105/official-lookahead-interpretation-20261105.md)
