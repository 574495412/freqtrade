来源：[作者仓库固定版本 d62416ea](https://github.com/0x-boss/quant_crypto_strategy/tree/d62416ea52620c2e9f53584dd5347ddf6718efd2)，具体为 `trendcore_spot.py` 明确支持的 `oi=None` 变体，默认 ASSET_VOL=0.45、TARGET_VOL=0.40、六小时决策和5%不交易带。作者称其为正式现货版本，不代表 Freqtrade 上游功能或经过验证的成熟策略。来源披露过业绩，选择存在事后偏差。默认含OI版本未通过数据准入；本轮没有复现该版本或作者完整历史账户。

- 连续窗口：**2025-01-01 00:00至2026-08-31 23:00 UTC**，每账户14,592个小时估值点。初始空仓；首个可执行信号为1月1日06:00。跨年不重置。
- 新跑4个实际钱包：1000和500 USDT，各单边20/13基点。费用由原生quote fee收取，含滑点代理，并非盘口成交模拟。目标配置保留1%现金，受原生最小金额和数量精度限制。
- 原生撮合与钱包来自固定 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`，运行时核验595个源码文件。信号、仓位回调、固定快照精度适配和只读净值观察器均为明确的本地扩展。
- 交易规则使用封存快照模型，**未认证历史每个时点的真实交易所规则**。此处比较仅在该模型下成立；不与40币永续组排名，也不解除其历史规则与资金费数据缺口。

## 数据、因果时钟与保留的失败

[Binance公开数据说明](https://github.com/binance/binance-public-data)对应48份2022年10月至2024年9月现货小时月档，逐一核验CHECKSUM、ZIP CRC及时间戳。BTC和ETH的2023年3月档均缺3月24日13:00这一小时；没有填价。数据完整性驱动的预热调整在账户运行前封存：从2023年3月25日00:00开始，保留每币30,144个连续小时，到2026年8月底。256天最长预热满足；不是作者全历史初始化。

每个左标记六小时组只在其结束后可用；不完整尾组不产生权重。6项针对性测试通过，包含作者纯趋势评分公式一致、不同时间单位、小时缺口拒绝、随机未来冲击与尾组时钟。真实输入的4个截断点也逐项通过。作者的账户模拟器没有运行；源码依赖的虚拟参考收益只作为本地波动刹车指标，采用来源固定10bp/5%递推，不作为业绩证据；其必要性和边界已在 `variant_freeze.json` 运行前明确。

保留初始时区与时间精度导入错误、发现BTC后又发现ETH缺口的过程及原始脚本。分析首版在读取另一个封存项目的相对路径字典清单时失败；`analyze_v2.py`仅修复清单格式兼容，原分析冻结保留，比较与门槛代码完全相同，未重跑或改变任何金融账户。

X/Twitter、YouTube、抖音的本轮定向检索没有取得该来源的原帖或视频；没有把搜索或作者宣传数字计为平台学习验证。固定树中未见代码LICENSE文件，README的CoinMetrics衍生数据许可与本轮自行取得的Binance小时数据分开记录；不存在生产准入结论。
