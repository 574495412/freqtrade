# 加密原生账户：几何路径＋三状态 HMM 的固定规则检验

**本轮完成 16 个真实 Freqtrade 历史账户及两组实际资金组合，未找到通过冻结门槛的更高净收益方案。** 联合信号在每侧 15 bps 成本下全窗口 −14.80%，回撤 32.98%；几何500＋HMM500组合 −8.83%，回撤 32.35%。每侧 8 bps 情景下也未通过。保留全部失败，不改方向、窗口、模型、股票／币种池、权重、门槛或费用挽救。

当前持续目标为加密研究；港美股组件工作不计入本轮成果。没有订单、部署、服务或模拟盘修改、提交和推送。目标仍未完成，无独立样本外或实盘资格。

## 原生链与资金核对

固定 Freqtrade commit `c051e9065c5b677f03817dd1f83cb980af1ed684`，595 个原始文件逐字节核验，未增加或修改该原生目录的 Python。实际执行 Configuration → StrategyResolver／IStrategy → DataProvider → Backtesting → Trade／Order／Wallets → 原生结果 ZIP。16 个进程退出码均为0；每个 ZIP、有效配置、完整逐时净值和资金轨迹均实际读回。

`protocol.json`、`plan.json`、统计信号及策略回调是本地研究扩展，不是 Freqtrade 上游自带 HMM。单一 BTC 时间序列状态信号不冒充横截面因子，Registry 与 factor_analysis 新增均为0。Freqtrade 原生没有 Vibe 的 SignalEngine／SQLite bench；本轮没有将结果跨引擎注册或称为 Vibe bench，原生 ZIP 才是账户执行证据。

独立从实际原生导出的成交重算 432 个含强制退出记录、1210 笔实际订单、346 次成交调仓，逐项检查费用、持股数量、1824 个完整8小时 BTC 资金费事件的归属与净值。16×14,592＝233,472 个逐时资金点核对；最大净值误差约4.19×10⁻⁸ USDT，资金费误差约7.11×10⁻¹⁵ USDT。每账户608个实际调仓预算，共9728个预算，最大预算净值差约2.27×10⁻¹³ USDT；方向、精度、最小交易额与实际指标映射均核对。

净值为每小时原生处理当前事件前的 mark OPEN 估值，包含持仓浮盈、原生已归属资金费与剩余退出费准备；不是盘中最差回撤。每侧15／8bps是冻结的聚合成本情景，资金费另计，不能认证真实订单簿、冲击或私有交易所结算。

日度目标按实际预算计算≤0.99×NAV的名义金额，3倍 cross 是统一保证金配置，不是3倍名义敞口承诺；用原生可用现金、数量精度和最小金额实际交易。小调仓无法成交会留下跟踪差异，不放大到最小单。实际500钱包因精度与交易门槛不能直接由1000曲线减半，故所有组合独立运行。

所有策略保留原生−0.99保证金止损与清算机制。3倍保证金下该止损并不等于价格跌99%；恒定敞口控制实际有一次自然止损和一次终点强制退出，所以它是带相同原生风控和日度数量目标的控制，**不是无止损现货买入持有**。不得与另一个 BTC buy-and-hold或既有 NFI 不同窗口／池／杠杆的头条收益直接排名。

原生回调包装会将 ValueError 记作 warning 后可能压制异常。本轮财务 worker 捕获该 logger 的 warning/error，并拒绝受影响账户；12项组件检查实际覆盖被压制的 ValueError 和 RuntimeError。16 个实际账户的 `callback_audit.json` 均无异常，不能把空跑成功算作账户通过。

## 固定来源的统计方法与迁移差异

采用 [benedictprimmer-web/regime_ensemble](https://github.com/benedictprimmer-web/regime_ensemble/tree/da7f8c47eb682b6f103a4021664c48d934413be2) 的 v5 expanding 路径，而非全样本拟合的默认展示。固定源码及版本已捕获；LICENSE 请求404，不声称许可证已确认。只调用几何、HMM、组合统计函数，未运行作者资金引擎或导入作者收益。

源研究为 SPY 日线，本地明确迁移至 BTC 永续。原始几何比率衡量路径效率，默认不带涨跌方向，不能擅自改成下跌反向开仓。保留15日几何窗口、训练段70/30分位阈值、3状态 diagonal Gaussian HMM、五项原始特征及源年度年化尺度sqrt252、504行最小训练／252行重拟合、0–4种子训练对数似然选优。这里252行是加密日历行，不暗改成1月1日年更，也不按策略收益选择种子。

特征为20／5日累计对数收益、20日波动率、距252日高点和200日均线距离，保留源码局部最少观察数。训练均值／标准差只来自训练段；状态由训练均值排序命名。测试以最后250条训练收益构建特征，但几何函数按源码只使用测试段，前14个比率为0；每次折叠的第一测试日按原始一日滞后规则持现金。原始测试段少于5行的资金报告保护没有用于阻止流式1–4行预测；完整正式样本的每折均≥5，完整预测不因此改变。

测试采用前向过滤概率，不用未来后向平滑或Viterbi标签。危机概率>0.5只将HMM分量置零，几何分量仍可产生半仓；不能误称“危机一律空仓”。联合得分阈值≥0.65全目标、≤0.35现金、中间半目标。源码HMM异常回退分支保留并记录，但本地金融准入拒绝回退模型；六个实际模型均无回退。

BTC原始日线2021-10-01～2026-08-31，共1796条，为统计训练提供预热；没有将资金窗口向后移到模型较好时段。完整6个滚动模型保存，独立log-domain前向过滤核对3873个概率单元，最大误差约9.99×10⁻¹⁶。三个时点实际重新拟合截断和未来扰动样本，历史特征／目标精确相等；作者公开过滤接口还重复核验最后一折。四个实际原生策略的175,968个小时指标单元精确核对。

这些是代码、因果时序和资金正确性的证据，不能把事后选择公开方法并测试同一历史段称为未触碰的独立样本外。
