## 数据、信息时钟和执行规则

258 份 Binance 官方月度 ZIP 逐一核对官方 SHA，覆盖六币各 700 个原始 quote-volume 日与各 1,824 个精确八小时资金费事件；OHLCV 和资金费与既有冻结原生文件核对。标记价使用实际已下载小时观察。公开历史并不证明私有账户资金费结算或未来可成交性。

分数、每日截面排序均在实际原生 IStrategy 的 DataProvider 输入内计算。T 日特征仅依赖 T−1 已完成日线；00:00 信号行经原生一根 1h 延迟，在 01:00 开盘处理，带 5m detail。前缀截断和实际未来扰动均检查。作者两个公开数值样例通过；独立 `math.fsum`／`statistics` 标量重算核对 10,944 个特征值，含统一价格放大不变性。辅助标量实现只用于核验，未作为交易输入。

同方向保留实际数量，排名改变才退出或换向，没有每日免费重置名义权重。原生 unlimited stake、最多两个槽位、99% 可交易资金，拒绝低于最小金额的向上补仓和延迟到非 01:00 的入场。没有方向、窗口、费用、币池或权重的结果后补救。

15／8 bps 为每边固定合并成本，实际写入原生 fee；这不是逐项撮合佣金、动态盘口冲击或可成交深度证明。1 倍 isolated 是杠杆配置，不保证持仓期间总敞口恒定为 NAV 的一倍。各 1,000 账户实际最大 mark 总敞口／NAV：Edge 1.164／1.148，Amihud 1.314／1.312，LowVol 1.781／1.777；净敞口也会漂移，不能称为已验证市场中性或 beta 中性。

## 实际账户核验

12 个进程 exit code 均为 0，实际 ZIP／配置／结果 SHA、初始本金、成本、1h＋5m、最多两仓逐项回读。实际原生特征与预检精确相同；1,050,624 个小时因子／目标行核对。所有实际入场的日期、方向、数量、价格与预算 trace 对齐；同方向持有和排名改变退出均核对。

独立 Decimal 核对实际成交、费用及终值；从实际导出成交重建每个小时的持仓数量、mark 损益、资金费及已实现现金，最大 NAV 误差约 1.03e−12 USDT。没有生成替代成交或反事实收益。六币资金费逐笔核对最大误差约 3.56e−15 USDT，累计 43,752 次账户—事件生命周期归属，没有同一账户同一币事件双重归属。正常调仓在 01:00，避开名义八小时资金费时点；这些仍是原生包含端点模型结果，不是交易所实际账单核验。

## 预测力和集中度：辅助诊断，不是回溯准入

冻结账户运行后，以实际原生特征创建 **3 个本地隔离 Registry 视图**，调用 Vibe-Trading 的真实 `factor_analysis` 9 次：全部日期、2025、2026 至八月三组。未改动 Vibe 全局 Registry、生产因子或任何运行服务。这里是跨项目诊断扩展，不是 Freqtrade 上游功能，也不能追认为资金测试前已通过准入。

## 结论与证据入口

本地高价差多头方向、Amihud 对照和固定 Edge／LowVol 分仓均未提供合格净收益。结论仅覆盖冻结的六币、方向、配置、公开数据和窗口，不推广为所有流动性策略无效；原文过滤器、全市场资格、动态冲击、独立样本外和私有结算仍缺失。无新策略可进入纸面观察或实盘部署。
