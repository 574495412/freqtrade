# Copula 原生失败边界：技术验证封存

这是此前加密研究的本地执行组件，不计入本轮港美股因子、股票账户或收益比较。固定上游 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`；新增 `freqtrade/optimize/copula_admission.py` 不是上游官方功能。

`CopulaRunAdmissionMixin` 只包围原生每个 5 分钟主时段：开始前按实际持仓检查已声明资金费缺口，完整消费原生事件后立即核验两腿实际数量／方向。原生事件逐项原样转发，没有提前消费下一事件、重写撮合／钱包、补单或自动平仓。该检查不能保证交易所原子成交。

真实 Configuration → Backtesting 初始化 → 继承的 `start()` → 原生 Trade/Order/Wallet 链运行了六个合成场景。原始 native1 与加固后的 native2 均保留，最终比较仅使用 native2，不当成十二个独立经济实验。
