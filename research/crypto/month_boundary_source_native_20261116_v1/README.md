# 月界日历效应：原生账户研究（拒绝）

本轮新增 12 个 Freqtrade 原生完整钱包，检验同一月界机制的两种来源规则及匹配持有对照。两个日历规则在两档成本下全窗口均亏损；十个预先固定的 500＋500 分仓组合也全部亏损。新增通过经济门槛的独立 alpha 为 0，未建立更高可比净收益。失败结果保留，不改参数救回。

## 完整账户口径

共同窗口为 **2025-01-01 00:00 至 2026-08-31 23:00 UTC**，每钱包 14,592 个逐小时事件前 OPEN 净值点；实际经过 607 天 23 小时。分年切片承接同一钱包资产，不重置资金，2025 切片止于 2026-01-01 00:00。BTC/USDT、ETH/USDT 共用一个现货 USDT 钱包，初始 1000 或 500 USDT，1 倍、不加仓、两个原生仓位槽、tradable_balance_ratio=0.99；原生 unlimited 分槽预算，不把第二币当成剩余现金全仓。

保守/较低成本分别为每边 20/13 bps 的统一报价费用代理；不是认证的历史订单簿成交成本。现货无资金费。1h 信号＋5m 明细，原生延后一根信号；已知下一小时日历状态只用于 UTC 月界时钟，不读取未来价格。输入增加 2024-12-31 23:00 一根前置小时，从共同起点空仓开始。终点按相同小时开盘价估值、扣剩余退出费储备；24 笔终端强平独立列示，不混入共同窗口成交。

## 工作流与验证

实际主链为固定 Freqtrade 2026.9、c051e9065c5b677f03817dd1f83cb980af1ed684 的 Configuration → StrategyResolver/IStrategy → Backtesting.start → Trade/Order/Wallet → ZIP。595 个上游文件逐个核验。本地 month_boundary.py、IStrategy、冻结市场精度适配和只读观察器属于扩展，不称上游官方日历策略或 Vibe bench。research_matched_nfi 标志仅选择已经封存的 BTC/ETH 精度契约，不表示执行 NFI 策略。

31 条生产者、输入、配置及协议路径在首次资金回测前冻结；12 个独立进程均正常退出，无资金重跑，始终单个资金子进程。内存监测每五秒采样；8 个短日历进程在首次采样前结束，因此其峰值 RSS 未知，不能据 4 个持有进程的样本认证全部内存峰值。封存器最初误以为每钱包都有 progress.json 而失败，已保存原因并如实列缺口，未重跑资金账户。3 个真实原生构造/信号转换预检核对 87,552 行，9 项唯一日历测试通过（覆盖 2000 闰年与 2100 非闰年及来源函数对齐）。共 344 个 Trade、688 笔模拟成交，含 320 个自然平仓 Trade 和 24 个单列终端强平；175,104 个小时净值点独立对账。344 次实际入场预算/精度均核验。

以候选无关 Decimal 成交现金账重建，净值最大误差 2.5871e-8 USDT。另从真实 ZIP wallet.feather 核对 330,216 条现金/持仓记录，175,104 个报价币时钟；现金归约扣除尚未确认的入场费储备。空仓时原生省略零币种余额，每处都用实际成交证明为零。原生已实现 profit_abs 的 8 位舍入作为明确独立分量列入 endpoint_components.json，不调整费用或收益。初版只读分析沿用零自然平仓旧研究的严格等式而失败，analysis_initial.log 与 analyze_initial.source.txt 已保留；修订仅补充原生舍入核对，未改任何冻结生产者、旧研究或经济门槛。

主要证据：[执行审计](execution_audit.json)、[原生钱包审计](native_wallet_audit.json)、[终点经济分解](endpoint_components.json)、[来源差异](source_method_gap.json)、[工作流归属](workflow_ownership.json)、[验证汇总](verification.json)。完整后验封存见 artifact_manifest.json 和 checkpoint_receipt.json；封存不等于预注册或独立验证。

## 适用边界

本轮是加密现货历史研究，不能作为港美股收益证据。共同历史已经用于前轮研究，且来源失败结论在冻结前已知；无独立未见样本。每币约 20 次自然月界事件，跨成本、资金和同机制变体的重复 Trade 不构成 344 个独立观察。日历是共同时间规则而非横截面因子，本轮新增 factor registry/factor_analysis/Vibe bench 均为 0；不能填造横截面 IC。没有纸面观察、真实私有账户结算、历史逐时交易所规则认证、部署或下单，研究目标仍未完成。
