## 数据与时点

Binance公开REST的30日OI保留限制不代表官方历史档案没有数据。本轮实际取得2024-12-28至2026-08-31的612个官方BTCUSDT metrics日档，每份按官方SHA256校验。原始176,253行保留，不从Bybit或其他交易所替代。使用`sum_open_interest`基础币数量，不把随价格波动的`sum_open_interest_value`当作合约数量。

精确选取整点观测，生成原生`date,open_interest_amount,open_interest_value`结构，14,688个小时中14,685个为正数。原报25个0值原样保留，其中3个整点无法用于相对变化；完整原始输入和失败记录保留。适配器要求6个连续正值计算5小时变化，native informative设`ffill=False`，不压缩时间行、不填0或前填缺口、不把0后的无穷增长当作买入。

整点观测假定5分钟后可用，同一行1h价格完成时才决定，下一小时进入原生撮合。这是明确披露的历史可用性代理，不是当年首见/传输认证。实际DataProvider读入、原生informative合并、每个条件的独立标量复算，以及3个截止点×3策略的截断/联合价格-OI未来扰动均已运行通过；不是完整官方lookahead/recursive认证或独立样本外。

20个BTC官方资金费月档另行下载并SHA校验，完整1824条8小时时槽及费率均与原生输入匹配。本轮BTC源例没有前一40币研究的AXS/TRB未解时槽；原生整小时资金费模型仍不能认证毫秒内先成交还是先结算、实际到账或盘中冲击。

## 冻结账户与结果

2025-01-01 00:00至2026-08-31 23:00 UTC，BTCUSDT永续、1000 USDT、1×逐仓、最多1个持仓、0.99可投资比例，两档每边15/8bps费用与滑点代理，另计原生资金费。原生5分钟detail；完整逐小时mark NAV含浮盈亏及剩余退出费预留。年度切片均沿用持续账户，不重置本金。终点强平收益另列，不当作自然盈利退出。

三组：原始OI上升确认、使用相同OI可用性掩码的价格突破、无OI掩码的价格突破。两个价格对照逐笔与全部14,592个NAV点在两档成本均完全相同，因而没有把数据掩码效应误算成OI改善。

|15bps|−41.13% / 50.89%|−57.55% / 64.68%|

OI确认分别少亏16.42/17.50个百分点，但仍亏损且回撤超过50%，两年度切片也亏损，冻结数字门槛失败。只有5次自然平仓，终点仍有1仓；不能以“少亏”或登记成功宣称新有效因子。作者的止损外退出未验证，本轮保留这个缺点，不在看到亏损后另加盈利退出来救活。

8bps价格对照略差也已按原生成交查明：两个成本的9笔成交时间、方向和价格相同，但2025-04-22的第7仓，8bps现金越过0.001 BTC数量阶梯，实际持有0.006 BTC，15bps为0.005 BTC；该仓的价格损失和资金费随数量增大。不能把本次离散复利钱包当作固定数量的成交后减费。详见`cost_quantity_diagnostic.json`；这不是放宽费用或修改源规则的理由。
