## 来源与机制

新固定 [earnings_surprise_analyzer](https://github.com/leeyawnnn/earnings_surprise_analyzer/tree/0e799363c7e1b123e03cd0a2965b6245e7d3faa6)，提交 `0e799363c7e1b123e03cd0a2965b6245e7d3faa6`。19 份实际 HTTP200 文件的 Git blob 与固定树逐字节一致；两份可选样本 sidecar 返回 404，原响应保留。代码 Apache-2.0，数据许可独立列在 NOTICE；没有称该研究练习为成熟盈利策略，也没有采用作者收益。

阅读全文包括 README、配置、原始 EPS、SUE、共识、事件对齐、价格、股票池及 pipeline；资金脚本只审阅入场、每日估值和成本路径，不称全仓审计。源主信号是季度历史 EPS 的季节性差、前八季度均值及样本标准差，阈值 ±1，20 个交易日持有；分析师共识 ±5% 是另一交叉检查，不能混为一个因子。现有 Vibe 的 SEC 月度 drift EPS 与 QC 月度 SUE 已单独读取，它们不是分析师预期，也没有因为新来源而重复注册或计作新 alpha。

源价格使用 `auto_adjust=True`，股票池为 2026-09-19 当期成员加加入日期，无法恢复已退出名字；源账户假定借券可用并使用假设成本，且把非有限单日收益设为 0。事件模块用固定美东 09:30/16:00 而非完整逐日半日合同。这些约定都不能直接替换本地同窗口股票账户、公司行动现金账和真实费用/结算。没有执行源账户引擎，也没有采用其统计显著性或回报排名。

## 实际输入审阅

重新核验 **514 份原始文件和其暂存 SHA、字段**，0 份具备本地所需的完整实际 EPS、公告前共识、观察时钟、财季、EPS 基础及原始文档绑定。这只陈述这批文件，不声称外部市场或整台机器没有数据。价格缺少该列不等于盈利预期差为零。

另外仅隔离执行两个完整阅读、无副作用的源纯计算函数 `standardized_unexpected_earnings` 与 `match_announcements`；没有导入外部包、运行下载器、完整 pipeline、因子评估或资金引擎。固定源样本有 1592 行季度 EPS、2208 行公告、23 个 EPS 证券；共 1587 个季度匹配。1248 个 SUE 非空且通过前期历史时钟检查的匹配中，**1122 个当期 EPS 的 `filed` 日晚于匹配公告日**。逐项见 source_current_eps_clock_witnesses.csv。

这是**输入阶段**、未经过源价格/成员/研究窗口/完整标签过滤的数字，不是作者最终账户笔数或本地目标池。后续备案较晚本身也不能证明公告没有发布相同数字。作者 README 明确承认假设后续 10-Q 与早先发布稿 EPS 一致、未逐项核对；本轮没有从原始发布稿认证这层绑定，故保留未知，不认定全部记录必然前视，也不把后续数据向过去回填。第四季度年度减前三季 EPS 的近似也不能代替已核对原始单季数字。

## 本地原生扩展

`freqtrade/data/equity_earnings.py` 增加不可变 EarningsValue 与共识输入检查；`equity_earnings_provider.py` 显式继承既有 EquityDataProvider，后者继承固定原生 DataProvider。它们是**本地研究扩展**，不是 Freqtrade 上游股票或 EPS 官方功能。

每个事件需明确证券、市场/币种、财季、GAAP/调整、基本/稀释及股份类别基础、原始文档和源 SHA，以及实际 EPS 和分析师共识各自发布与观察时刻。共识必须严格早于实际公告已观测；实际值须截至原生 callback 时钟已观测。不同财季/基础/证券/角色拒绝匹配；缺值、时钟、原文或接近零估计保持 unknown，非有限或布尔值不产生分数。负估计使用绝对值分母；源百分比核算为 `(actual-estimate)/abs(estimate)*100`、低于 0.01 未知、截到 ±200，不对已有百分比再乘 100。

原生 DataProvider 的真实 `_set_dataframe_max_date` 供给观察时刻；未来或无日期事件不向回调泄露其存在，已观察但共识未知的事件保留未知。返回对象是副本；重复事件/修订、未登记证券、市场币种冲突拒绝，修订选择和完整共识历史需另立合同。财季完成按所属市场当地日历日期检查。提供 SHA 与声明时钟仍不能认证来源真实性、实际 first-seen、是否存在遗漏修订或完整事件覆盖。

这不是新策略，不产生入场、资金、账户或 Registry 分数，也没有更改普通历史股票入口的拒绝。补上的只是后续原生因子研究可复用的输入边界；真实数据没有因接口可用而自动准入。
