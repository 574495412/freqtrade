## 固定窗口与实际结果

日历窗口为 **2025-01-01～2026-08-31**。交易日来自本地 `exchange_calendars 4.13.2`：XNYS 416 日，XHKG 408 日；保留开收盘、午休与半日安排的完整 schedule。这是软件日历合同，不声称已逐日获得交易所独立认证。日线时间戳是交易日标签，不能充当实际成交时间。

保留现有美股 503 个和港股 11 个输入的完整清单。它们是已有研究输入，不代表无生存偏差的全市场证券主表。美股来源于既有原生研究的桥接清单，港股 11 个源文件逐一核对原运行的 SHA。股票输入没有加入新行情或补写财务数据。

487 个通过输入的 **1,012,520 个 OHLCV 数值**与原输入精确一致。27 个美股输入含非有限价格或成交量，全部拒绝；不能删除这些名字后声称原始完整证券池通过，也不能据此推断真实股票始终不可交易。退市、合并、拆分、后继证券等需要事件和证券生命周期支持。

源输入共有 37,675 个非有限 OHLCV 字段；原生默认加载会把其中 **17,567 个**变为有限值。这与额外补出的日历行是不同计数，不能相加。二者说明默认加密历史清洗不适合直接作为完整股票输入证据，不构成对加密用途的错误判断。

## 原生实现与本地扩展的界限

- 引擎固定为 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`，运行前逐一核对来源清单中的 595 个文件。实际历史 API 从 `/Users/chrise/GitHub/CZ-Agent/vendor/freqtrade` 导入。
- 本地扩展在 `freqtrade/data/history/equity.py`，继承原生 FeatherDataHandler，并调用原生 `load_pair_history(fill_up_missing=False)`。原始行先接受唯一、有序、完整日历及有限正价格/有效成交量检查，避免原生去重聚合掩盖异常。
- 原生默认 crypto 加载路径不变。16 项边界测试通过；新增模块及测试 Ruff 通过。这里的成功仅证明本扩展已核验的历史接入行为。
- **Backtesting 和 DataProvider 的默认加载仍未替换**；本轮没有调用股票策略的 Backtesting.start。股票执行时钟、整股/整手/价位、卖出侧收费及税、可用/未结算现金、股息权利/付款、公司行动和退市，以及空头借券/召回尚未接入完整 Freqtrade 账户。
- `require_complete_equity_account_support()` 对当前未完成的合同明确拒绝。数据接入成功、Registry 注册、IC 或其他项目的 bench 均不能解除该缺口。

旧 Vibe-Trading 的 Registry → factor_analysis → hypothesis/config → SignalEngine → backtest → bench 仍是该项目结果的所有者。本轮未修改 Vibe 因子或重新计数旧结果。下一项股票因子仍须经过相应原生因子验证；Freqtrade 账户还须完成本地执行扩展并输出实际成交、现金流、逐时/逐日 NAV 和运行状态。

[QuantConnect 官方 GitHub 配对模型](https://github.com/QuantConnect/Lean/blob/78de2ccd1e8d1544bd69f1b0494493f56559ec12/Algorithm.Framework/Alphas/PearsonCorrelationPairsTradingAlphaModel.py)及基类、许可证已下载并固定 SHA。实际代码以对数价格变化的 Pearson 相关选择配对，基类使用价格比的 500 点 EMA 和百分比偏离带；默认阈值为 1%。代码中的“2 std”注释不能替代真正公式。它与既有动量及截面 PCA 残差的机制和执行合同不同，但尚未完成与全部既有因子的去重或预测力验证。
