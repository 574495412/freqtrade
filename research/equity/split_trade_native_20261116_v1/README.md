# 港美股原生账户工程：整数拆合股持仓与成本单位

**本轮20个完整合成原生生命周期、20份实际ZIP及2个预期零股拒绝完成；独立核对280个账户边界、2240个现金/股息/NAV标量通过。新增完整真实港美股历史账户、组合账户、factor_analysis、bench及接受的独立alpha均为0，尚未证实更高可比净收益。整体目标未完成。**

原始目标仍为503美股、11港股，2025-01-01至2026-08-31，USD/HKD分别核算。1542份原始/暂存/原生输入路径SHA未变，没有按结果删证券、缩窗口或把加密收益计入股票。此轮是工程集成，不是扩策略或选择更高收益候选的证据。

## 实现及原生界限

固定Freqtrade上游c051e9065c5b677f03817dd1f83cb980af1ed684的595文件逐项核对。新增一个明确的本地原生核心扩展：Backtesting的LocalTrade构造调用改经_create_trade，默认仍返回完全相同的LocalTrade(**kwargs)。AST审核确认只替换1处构造调用、增加1个默认方法，其余原生AST完全相同。普通构造路径及空事件子类的真实财务轨迹，分别与前轮两市场夹具逐项一致；不声称验证了所有加密策略或所有交易模式。

这是上游固定版本加本地扩展，不是上游官方股票支持。实际运行仍经Configuration→StrategyResolver/IStrategy→继承的Backtesting.start→原生Trade/Order/Wallet→实际ZIP与净结果侧文件，没有替换撮合或另建主要账户模拟器。

新增四个本地模块：

- data/equity_splits.py：只接受明确已实施、具备来源SHA和已知时钟、绑定具体证券及执行开盘的拆合股。公告和批准本身不能充当已实施事件。新/旧数量比例使用精确分数。
- persistence/equity_trade.py：继承原生LocalTrade，保留原始订单数量、价格、时间和现金金额。只在原生重算方法内使用不可变的单位视图，返回后恢复原始订单。每次重算都能保持拆股后的剩余数量和原成本，避免直接改股数被下一次原生重算覆盖。
- equity_split_wallets.py：在原生钱包时钟推进时更新持股单位，沿用原生费用、交收及股息钱包；失败恢复交易状态。股息按各自除息开盘的单位计算，而非按今天单位重估旧应收。
- optimize/equity_split_execution.py：通过上述构造接口创建绑定同一合同的实际原生Trade，仍使用原生开盘订单和成交。

同时在既有费用钱包增加默认不改变数量的quantity_asof接口，供股息权利及闭合Trade的净数量校验使用。默认语义保持不变；旧股息40项、净值37项回归通过。

实际支持范围限于同币种普通股份、无杠杆多头、单笔入场及全额退出、整数剩余权益；不支持零股现金、due bills、跨证券后继、股票分派、借券、DCA、部分退出或跨事件挂单。股价与交易整手/价位仍由独立的明确输入和执行合同提供，生产模块不自动制造拆股后报价。

## 完整合成生命周期

美元和港币各11次独立离线进程：普通默认构造、空事件子类、2拆1后卖出、1合2后卖出、持股期间2拆1、持股期间3拆1、首次开盘即拆股后买入、先拆后合、未来2/4倍反事实，以及6股遇1合4的零股拒绝。固定1000初始现金、600名义下单、继承的7个合成交易日、原有明确费用合同。不是认证交易所日历、历史市场报价或经纪实际到账。

20个完成运行共60笔原生模拟成交和280个开/收盘账户边界。每份ZIP含已关闭的首个Trade及2笔原始成交；另1笔买入和期末未平仓状态保留在native_trace.json和equity_net_result.json。没有虚构期末卖出。两个零股案例各留下1笔已经发生的合成原生买入及拒绝回执，不计为完成账户或完整ZIP。

实际3拆1案例显示：6股、600原始成本成为18股，平均成本约33.333333333333336，原始买入记录仍是6股×100。平均成本不是交易报价，不能按0.01价位误舍入为33.33后凭空减少成本。此处浮点平均只是原生计算表达；独立Decimal对账容差为1e-8。

拆股后买入使用当次真实原生报价与新单位，不重复乘已生效的数量比例。已付/应收股息按实际除息前持股计算，付款只进入现金一次。追加两市场检查确认后续拆股不会放大已经产生的6元股息应收；另两项钱包检查确认零股失败恢复现金分区、时钟及原生持仓。这4项为运行后的补充组件验证，未增加原生启动或经济样本计数。

未来事件2→4倍只改变事件日及以后的单位，前6个交易日的完整财务边界相同。完整原始报价文件SHA随未来报价变化而变化，审核仅剔除该全文件来源SHA再比较财务前缀，保留数量、价格、时钟及所有现金/NAV字段；没有假称来源字节也相同。每个运行各自的原始文件SHA独立核对。

两个零股案例在第二天开盘前拒绝，原持仓6股、成本600、原订单及上一收盘时钟保持；没有生成完整结果。钱包现金恢复另有明确组件检查，不能把拒绝案例的缺失完整现金轨迹当作已完成账户。

## 独立核对和验证

独立审核不导入候选策略、单位/成本模块或资金组件。从原始夹具、实际订单及拆股/股息/费用/交收合同，以Fraction/Decimal重建数量、原现金流、按原成交单位收费、未结算卖款、股息应收/到账和NAV。复用的旧费用算术审核函数哈希已冻结，它不是主要资金引擎。

2240个标量误差均低于1e-8，原生ZIP的原始订单与侧文件逐笔一致，闭合Trade的原生毛利润与原现金流一致。末期实际持股成本、净结果及抽样开/收盘回撤也分别核对；该回撤不包含未观察到的日内最坏损失，本地净结果的CAGR/Sharpe为空；ZIP自带毛统计仅为诊断。

39份执行源码/协议/来源路径在启动前冻结，22次子进程均终态exit0；其中2次是程序明确识别的预期不支持事件，不改称完成回测。23项不同的新组件检查及77项既有回归通过，19项初始测试的复跑不重复计数。此前隔夜研究204路径及股息生命周期377路径封存逐项未变。

8个生产模块严格Ruff通过。研究脚本使用记录的S101/E402/C901豁免；已冻结的freeze.py保留一条不影响执行的未使用json导入，该单文件另用F/E9并排除F401检查。初始样式、补充测试的导入顺序错误、验证器遇到两种旧清单结构的错误均保留；修正只涉及验证工具，没有重跑或调参金融结果。

## 后续完整收益链

普通EquityBacktesting仍在原生构造前拒绝未准入股票账户；ABC单证券合成生命周期限制没有解除。完整原始池的历史证券主表、名义/总回报单位、已实施公司行动、零股/证券后继、历史整手价位、税费适用、交收与股息、退市及终点合同仍须准入并集成。
