# 港美股 Freqtrade：现金股息权益、付款与季节性来源核验

**本轮补上了本地原生现金股息组件，尚未取得更高可比净收益的新组合。新增完整历史股票账户、组合账户、已接受独立因子均为 0；历史收益与回撤仍未知。**

原始比较范围保持 503 个美股、11 个港股，2025-01-01～2026-08-31。美元与港币分别核算，不重置资金、删亏损证券、缩短窗口或缩放拼接曲线。没有下单、部署、服务修改、提交或推送；此前加密实验不计入股票证据。

## 原生组件完成了什么

引擎仍为 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`，逐字节核验 595 个原始文件。新增 `freqtrade/data/equity_dividends.py` 和 `freqtrade/equity_dividend_wallets.py`，显式继承现有本地 `EquityFeeWallets`；Backtesting、Trade/Order、Wallets 的实际成交与资产状态仍由固定原生代码拥有。它们是本地扩展，并非上游已支持完整港美股账户。

现金股息按实际原生订单确定数量：**仅在明确除息开盘时刻之前已成交的净持股获权益**。除息开盘或之后买入不补获权益；除息后卖出不取消既有待收款。加仓、部分退出与已关闭 Trade 的历史分别保留，权益不从平均成本或当前持仓倒推。已观察订单缺失或被改写会拒绝更新。

每个普通现金股息显式绑定证券、同账户币种、公告及税率可知时刻、精确除息开盘、每股金额、税率、来源 SHA，以及可选的付款可用时刻与其通知。只支持名义未复权报价、普通同币种现金股息、明确的分级分币四舍五入合同。来源 SHA 证明所绑定字节，不能认证发行人、历史 first-seen、税收身份或实际经纪到账。

**除息待收款不进入可用现金，付款后才可供原生实际买入使用。** 付款日期未知时保留待收，不假设到账；付款通知晚于除息时，早期报告不暴露该通知。未收净股息进入净值一次，已付净股息进入现金一次：

`净值 = 已含实际交易费用和已付股息的总现金 + 实际持股市值 + 未收净股息`

卖出未结算款已含在总现金里，不再重复加；股息支付将待收转为现金，不自行增加净值。原生默认 Trade 利润与统计仍未纳入股息／本地费用，不能当成股票总净收益；组件单列交易现金利润、已付股息及未收款，不据此计算完整策略胜率。

现有三个**本地**组件作了兼容扩展：结算钱包增加默认 0 的累计已结现金入口，费用钱包在费用核验前计入该现金，净值组件支持未收股息。初始资本不变、没有外部注资。否则已付股息支持的真实买入会被旧现金检查错误拒绝。修改前字节在 `owner_before/`，变更及当前哈希见 `technical_amendment.json`；旧报告和旧收据保留，旧哈希不冒充新版组件认证。

## 验证与实际边界

**197 项不同检查通过：40 项股息检查和 157 项既有结算、成交前、历史费用、净值回归。** 生产模块完整 Ruff 及研究脚本语义检查通过。原生合成样例覆盖美股 T+1、港股 T+2 测试合同，共 6 笔真实原生合成成交、12 个快照；独立 Decimal 审核 84 个现金、数量、费用、待收、已付和净值单元。

验证包括除息边界买入、除息前加减仓、卖出后收款、付款前后、付款未知或晚于窗口、晚到通知、未来事件金额扰动／截断、缺失或变更已观察订单、现金含费不足、重复更新，以及完整声明净值网格。空股息合同与旧钱包同一实际成交路径精确一致。

样例证券 `ABC`、股息、税率、费用与日历均为技术夹具。测试壳直接调用真实原生成交方法，隔离数据库提交、清算更新和无关回调；没有执行完整 Configuration／IStrategy／Backtesting.start 的历史账户链。样例数字不是历史收益或经纪税率证明。

保留首次 lint 失败、缺少 bs4 的来源辅助请求失败以及独立审核的同刻成交边界错误：原审核仅按时间戳误将同刻尚未成交的卖单纳入除息前快照，后改按快照实际完成订单数确定边界。该修正只改变审核选取，没有改动原生成交、策略、费用或股息结果。最终全部通过。

尚不支持外币股息兑换、特殊股息 due bill、股票股息／以股代息、ADR 托管费、退市、合并、拆股或付款取消／修订；不能将这些事件压成普通现金分红。输入所有者还须提供完整事件覆盖及历史可知性证据。`EquityBacktesting` 完整账户入口继续在原生初始化前拒绝，因此本轮没有完整历史净收益与 bench。

## 不同机制来源：预期股息月份

固定 [OpenSourceAP DivSeason 源码](https://github.com/OpenSourceAP/CrossSection/blob/9f053398c4995651d822e90d81526d0644c6f3e5/Signals/pyCode/Predictors/DivSeason.py)及保存函数全文已读，许可证 GPL-2.0；辅助函数只阅读相应滚动／滞后封装，未声称读完所有函数。没有执行源因子、源资金引擎或复制源码到交易模块。

它研究预期分红月份的需求压力，区别于追逐当期高股息率。源码筛普通现金分红，用频率代码区分季度／半年／年度，对来源月份分别使用 2/5/8/11、5/11、11 个日历月滞后；来源月状态用于后续持仓月。保存函数只生成年月标签，不额外移位。不能把这些滞后误称为同一标签月的 3/6/9/12，或在该月未完成时提前交易。

实际核验原 514 份价格／特征 CSV 的字节哈希和列结构：**0 份具备该来源要求的历史分红频率编码／身份／除息事件面板**。该结论限于这些输入，不声称全部 SEC/HKEX 公告、整台机器或外部市场不存在数据。没有准入面板是未知，不能变成“历史从不分红”。来源在完整分红／主表基础上的零填充，不授权对本地缺失输入补零。

因此本轮在输入门槛停止该候选：Registry、factor_analysis、资金账户、hypothesis／配置／SignalEngine 历史执行与 bench 新增均为 0。没有计算对其他因子的数值去重，也没有声称发现独立 alpha。不得用当前股息率、按间隔猜频率或事后修订日程代替所需历史输入。
