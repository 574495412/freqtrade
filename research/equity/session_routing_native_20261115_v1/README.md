## 本地原生扩展

上游仍固定 Freqtrade `c051e9065c5b677f03817dd1f83cb980af1ed684`，逐字节核验 595 个原始文件。新增 `freqtrade/optimize/equity_sessions.py` 是本地扩展；原始 Backtesting、Trade/Order、Wallets 及已有股票组件均未修改。完整 `EquityBacktesting` 入口仍在原生初始化前拒绝。

本模块通过原生 `_get_ohlcv_as_lists` 和 `_time_generator` 扩展点接线，**实际 `Backtesting.time_pair_generator` 没有重写**：

- `EquityDailySessionPlan` 绑定同市场、币种、固定证券清单及完整软件交易日日历，按准确交易日开盘推进，而非每 24 小时推进。保留开收盘、午休、半日及夏令时。
- 原生 `IStrategy.ft_advise_signals` 在完整数据上生成信号，先滞后一个交易日，再选账户窗口。首个账户交易日保留此前完成信号，不因先截窗再滞后而丢失。信号缓存继续使用交易日标签，不伪装成开盘时已知的当前日收盘。
- 每个原生回调、钱包捕获及资金分配之前，先推进实际费用／股息／结算钱包，再设置 DataProvider 的可见截止时刻。回调仅看到已经收盘的日线。
- 不匹配的时钟、午休、币种、证券清单、已存在成交历史、动态池、做空、数据库及服务模式、分钟明细均拒绝。当前只接日线多头现金的技术路径。

这不是完整股票回测入口。原生每日 OHLC 的高低价依然是整根柱的资料，不能认证盘中成交先后、开收盘竞价或某个订单的实际可成交性。设置正确时钟也不能自动证明任意策略公式没有未来信息。

全部通过输入的 OHLC、上一完成信号、标签和开盘映射共 **1,616,704 个标量核对**，另有 **2,916 次实际回调可见性检查**。28 项拒绝与原记录逐项一致，不能把它们从原始证券池中抹掉。软件日历仍来自既有 `exchange_calendars 4.13.2` 文件，不声称逐日交易所独立认证或逐条历史行情 first-seen 认证。

**253 项不同检查通过：26 项新时钟接线检查、227 项既有股息／费用／结算／历史／DataProvider／入口检查。** 生产模块完整 Ruff 与研究脚本语义检查通过。技术加固后的真实输入复跑与初始结果完全相同，不重复计算成新 alpha、额外独立样本或新资金账户。

另有 **14 次实际原生生成器产出、4 笔实际原生合成成交、16 个净值快照**，验证回调前时钟、买卖费用、T+1/T+2 待结算及后续解锁。证券 ABC、收费及现金日历均是技术夹具，不是历史经纪合同。完整真实股票输入只运行到行转换；其资金生成器未运行。合成探针直接调用原生生成器与成交方法，不是 Configuration／Backtesting.start 历史策略账户。

保留初始夹具长度和 pandas 时间精度不一致的三轮失败日志。午休与已有成交历史检查是结果前的技术加固，修改前代码、原始通过记录及修订哈希均保留。首版探针通过 MRO 下标标注生成器模块，后来加入费用 mixin 后标签失准；已改为直接读取原生方法归属，旧轨迹与源码保留，未改变经济事件或测试资金。

## 多来源继续学习：隔夜收益不等于可收割账户

方法按隔夜／日内复合回报及其比重排名，包含流动性筛选和不同回溯期。其“剔除实际隔夜涨跌绝对值超过 8%”只能作为事后敏感性诊断，不能直接变成此前收盘可知的入场条件。默认调整价格重建也不能代替名义成交价格、股息待收／税款／付款及现金结算账户。没有执行这一外部收益引擎或生成本地排名收益。
