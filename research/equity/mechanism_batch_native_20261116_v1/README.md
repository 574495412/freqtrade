## 实际执行与审计

实际路径为固定Freqtrade原生历史加载→现有本地EquityDataProvider→实际StrategyResolver/IStrategy→当前Vibe Registry→实际FactorAnalysisTool。Freqtrade上游固定 `c051e9065c5b677f03817dd1f83cb980af1ed684`，595份原生文件逐项复核；本批跨项目接入是本地扩展，不能称作上游官方股票支持。

原生严格加载接受475美股、11港股，保留全部28个美股拒绝记录；原始514个身份没有删除。每个市场只用准入原始历史的完整横截面进入Registry，先剔除无效输入，再进行横截面市场均值或标准化，不靠计算后掩码清除污染。Alpha101 #6的当前拥有元数据不包含港股，故港股没有该调用，也没有静默放宽市场声明。

29条实现/协议/源码/拥有者路径在计算前冻结。三个真实子进程依次计算、诊断及审计，全部终态exit0。没有资金回测失败后的金融重跑。6项有意义的接口检查通过；保留初始lint修正日志，不把重复测试算作新增样本。研究脚本的Ruff检查明确排除S101/E402/C901，未宣称这些脚本通过不带排除项的检查。

实际产出829,335个有限因子值。全横截面三处未来扰动及截断重新调用Registry，比较3,977,974个前缀单元，含预热未知及重复前缀，不是独立预测样本。13,023项实际回调边界检查确认收盘前不能见到当天分数，收盘时才可见；这仍是软件日历可见性模型，不是逐条历史数据发布时间认证。

独立审核不导入候选策略、Registry或因子计算核心，以原始原生报价/量重算全部829,335个有限分数。BAB和ILLIQ最大绝对误差分别约1.24e−14和1.42e−14；Alpha101 #6为9.37e−9，在冻结的1e−7数值公差内。审核保留ILLIQ原生safe_div的两次带符号1e−12约定，不把其当精确无扰动理论除法。

独立重建1,440,772个CSV标签单元，并核对4,918个IC行、14,754个实际原生分组NAV单元，分组最大误差8.88e−16。计数包含全段与年度切片的重叠；不是4,918个独立经济样本。分组NAV是费用前报价标签统计，不能当作含持股、现金、交易费用、股息及期末估值的投资账户收益。没有用其CAGR、Sharpe或净值末值排名。
