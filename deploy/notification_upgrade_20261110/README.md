## 上线后的内容

1. 保留运行中交易进程的13类原生事件模板，转发端即时将已知文本适配为企业微信卡片，无须重启交易。区分开仓、加仓、减仓、平仓、待成交及撤单；展示原生交易编号、币种、方向、杠杆、数量、价格和引擎盈亏。未知旧消息仍保留。
2. 补充现货/合约运行摘要：资金上限及预算、配置币池、最大仓数、心跳、本地订单/有成交订单/持仓/追加入场次数。已平仓后才计算胜率及已平仓周期的引擎净盈亏；不把空账本或读取失败显示为高胜率/正常。
3. 每30秒只读检查两个既有实盘进程、原生账本与有限长度的日志尾部；不调用交易所接口，不加载交易密钥。识别418/429、市场加载错误、K线请求失败、引擎错误、原生 Webhook 失败、心跳缺失、进程退出、账本不可读和本地选币快照过期。
4. 只在初次升级和观察状态/账本计数变化时发送摘要；同一错误持续出现不逐条推送。日志报告的418未到期时间会被保留，避免安静日志被当成已恢复；截止时间只是日志报告，不保证交易所届时已解除限制。错误消失只代表近期监控项变化，不认证全部行情新鲜度。
5. 监控状态与摘要入队同一事务提交，通知服务重启不反复发送相同警告。原生交易事件不做相似文本去重，避免吞掉连续加仓/成交；原有待发队列及失败重试保留。持久化前隐藏URL、签名与密钥字段。

交易盈亏来自 Freqtrade 引擎事件/已平仓账本，不是交易所佣金逐笔核对证明。摘要不计算账户总权益、未平仓浮盈亏、全账户收益或历史回撤；实际手续费、第三币佣金估值和成交一致性仍以原有逐笔验收为准。
