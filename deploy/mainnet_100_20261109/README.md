## 固定额度的本地原生扩展

单独的原生 `available_capital` 会随已实现盈亏扩张，不能称为固定上限。`CappedWallets` 是明确的本地原生Wallets子类：总交易预算取原生结果与99U的较小值，亏损仍降低可用预算；盈利或后续充值不扩大预算。可用额度还扣除未成交DCA委托的全额预约；原生账本已预约的新仓首单不重复扣除。普通开仓与追加仍使用原生钱包验证、撮合、结算及手续费逻辑。

100U限制指本策略的投入/保证金预算，不是账户总亏损保证、累计成交额上限或持仓按现价计算的恒定名义敞口上限。3倍按投入计算的名义金额不超过300U，持仓市值随价格变化。费用/资金费、最小委托和原NFI宽止损边界仍适用；未新增交易所保护止损。账户其他手工操作不属于本进程控制范围。

6项本地测试通过：盈利不能扩预算、亏损降低预算、亏尽停止、未成交DCA预约、初始订单不重复预约、只读路径不能创建Worker/Popen，以及V3账户余额缺省canTrade时改由accountConfig确认权限。原生StrategyResolver与两侧schema离线校验通过，未构造交易客户端。认证GET检查确认两侧资金满足100U、无存量订单/头寸/库存，合约单向/单资产模式，交易权限及合约80币带单白名单通过。仅证明检查时点的条件，不是实际下单通道验收。现货带单专项白名单仍未独立完整验证。

旧退出时间诊断的6处警告已在原范围内修复；回填名单后见偏差及独立样本外缺口仍保留，`production_eligible=false` 保留。原策略的 `stoploss=-0.99`、交易所止损关闭也未改变。本目录不将用户手动选择等同于已通过研究晋级资格。
