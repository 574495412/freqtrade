# 用户手动启动：现货100U、合约100U保证金

用户明确要求币安主网、现货和合约各最高100USDT；随后确认合约按保证金上限、逐仓3倍理解。本目录只准备配置、离线检查和认证GET检查。代理未执行默认启动命令，未实例化实盘Exchange/FreqtradeBot、未下单、撤单、划转或更改账户设置；没有安装实盘自启动服务。

在 `/Users/chrise/GitHub/freqtrade` 根目录由用户本人执行：

```sh
.venv-paper/bin/python -B -m deploy.mainnet_100_20261109.manual
```

**默认命令会启用两个真实交易进程，可能随即下真实订单。** 命令先重新核对源码/配置摘要，执行GET账户、挂单、持仓/库存、权限及交易对准入检查，成功后才提交两个后台原生Worker启动请求。输出PID仅代表提交启动，不代表已健康运行或成交。已有实盘数据库/PID时拒绝重复启动，需核对状态，不能盲目重复运行。子进程日志和PID在各自私有状态目录；这是本机进程，不是远程托管。

仅检查、不启动：

```sh
.venv-paper/bin/python -B -m deploy.mainnet_100_20261109.manual --check-only
```

## 实际配置范围

| 市场 | 策略 | 币池/槽位 | 额度 |
|---|---|---|---|
| 现货 | NFI X8＋Top Coins多头首仓1.25倍 | 现有36币，最多6仓 | 99U仓位预算、1U外部费用预留 |
| 永续 | 相同首仓规则，原日更优化版 | 前一完整UTC日成交额前80，最多12仓，逐仓3倍 | 99U保证金预算、1U外部费用预留 |

合约复用独立公开行情选择器的日更快照；过期、未来输入或原生币池不同会拒绝新初始委托。旧仓加减仓和退出规则保留。现货没有同口径2026全年回测，不能称为现货最优，也不沿用合约201.24%的收益。合约历史回测的本金为1,000U，现为100U；交易所最小下单量、资金取整和新增限额会改变成交，不能按比例保证相同收益。

存盘配置均为 `dry_run=false, initial_state=stopped`。仅用户默认手动命令在子进程内切换为RUNNING；代理没有调用该路径。两侧使用独立账本、独立凭据。私有文件在 `user_data/deployment/mainnet-100-20261109/{spot,futures}/`，权限600、目录700、Git忽略。现货只用独立现货带单变量，不回退到合约密钥；不读取真实钱包全额作为策略预算，不划转资金。

## 固定额度的本地原生扩展

单独的原生 `available_capital` 会随已实现盈亏扩张，不能称为固定上限。`CappedWallets` 是明确的本地原生Wallets子类：总交易预算取原生结果与99U的较小值，亏损仍降低可用预算；盈利或后续充值不扩大预算。可用额度还扣除未成交DCA委托的全额预约；原生账本已预约的新仓首单不重复扣除。普通开仓与追加仍使用原生钱包验证、撮合、结算及手续费逻辑。

100U限制指本策略的投入/保证金预算，不是账户总亏损保证、累计成交额上限或持仓按现价计算的恒定名义敞口上限。3倍按投入计算的名义金额不超过300U，持仓市值随价格变化。费用/资金费、最小委托和原NFI宽止损边界仍适用；未新增交易所保护止损。账户其他手工操作不属于本进程控制范围。

6项本地测试通过：盈利不能扩预算、亏损降低预算、亏尽停止、未成交DCA预约、初始订单不重复预约、只读路径不能创建Worker/Popen，以及V3账户余额缺省canTrade时改由accountConfig确认权限。原生StrategyResolver与两侧schema离线校验通过，未构造交易客户端。认证GET检查确认两侧资金满足100U、无存量订单/头寸/库存，合约单向/单资产模式，交易权限及合约80币带单白名单通过。仅证明检查时点的条件，不是实际下单通道验收。现货带单专项白名单仍未独立完整验证。

旧策略版本的退出时间诊断、回填名单后见偏差及独立样本外缺口未被本次工程准备消除，`production_eligible=false` 保留。原策略的 `stoploss=-0.99`、交易所止损关闭也未改变。本目录不将用户手动选择等同于已通过研究晋级资格。

官方只读接口参考：[现货账户](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/rest-api/account)、[合约账户](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/account)。合约余额V3不返回canTrade时，按单独账户配置接口确认；初次校验错误及GET响应保留在私有带时间戳检查目录，未发生真实订单。
